# 글자별 원국·대운·세운 관계 목록 점검 — 2026-11-14

## 결과

현행 등록 관계 범위에서 글자별 목록의 누락·중복·깨진 참조를 발견하지 않았다. 코드 수정은 하지 않았다. 실제 HTTP 응답을 검증했으며 프론트엔드 화면의 렌더링·클릭·정렬은 확인하지 않았다.

## 범위와 확인 방법

실제 출생 입력 6건에 대해 루트·원국 상세 각 1회, 대운 10개와 세운 100개를 각각 조회했다. 총 672 HTTP 요청, 관계 그래프 666개, 글자 노드 누적 7,822개, 관계 누적 27,664개다. 누적 수에는 선택마다 반복되는 원국 관계가 포함되며 고유 관계 수를 뜻하지 않는다.

| 출생 입력 | 원국 관계 수 | 대운 선택 | 세운 선택 |
| --- | ---: | ---: | ---: |
| 1995-5-12 14:30 sol 남 | 20 | 10 | 100 |
| 1990-1-8 18:00 sol 남 | 24 | 10 | 100 |
| 2023-2-1 00:00 lun_y 여 | 23 | 10 | 100 |
| 2000-2-29 23:59 sol 남 | 19 | 10 | 100 |
| 1990-1-1 12:00 sol 여 | 22 | 10 | 100 |
| 2023-2-1 00:00 lun 여 | 19 | 10 | 100 |

각 그래프에서 확인한 항목:

- 모든 글자의 relation_ids가 그 글자가 참여한 중앙 관계 전체와 정확히 일치하며 중복이 없다.
- 투간 전용 참조는 relation_ids에서 투간만 선택한 결과와 일치한다.
- 관계의 소속 목록과 실제 참여자의 소속이 일치하며 참여자 상세 정보가 모두 있다.
- 다자 조합의 모든 글자가 실제 참여자에 포함된다. 같은 글자라도 소속·위치 ID를 구분한다.
- 모든 관계에 제목·본문이 있으며 explanation_status=partial은 0건이었다. 이는 현재 평가 범위 안의 설명 완결성이다.
- 대운·세운을 선택해도 원국 관계 본문과 글자 기본 정보·통근 정보는 유지된다.
- 세운 조회에서 해당 대운을 단독 선택했을 때의 모든 관계 ID·본문이 보존된다.
- 운이 참여하는 관계는 서로 다른 소속을 연결하며 detected 또는 candidate_only 상태를 유지한다.

소속 구성별 관계 누적:

| 소속 구성 | 관계 수 |
| --- | ---: |
| natal | 14097 |
| daewoon + natal | 6309 |
| natal + sewoon | 5789 |
| daewoon + sewoon | 1394 |
| daewoon + natal + sewoon | 75 |

## 각 글자의 실제 목록 예시

양력 1995-05-12 14:30 남, 세운 2026 선택. 해당 대운은 index=2의 戊寅이며 세운은 丙午다.
[글자별 참조와 중앙 관계·표시문 추출 JSON](character_cycle_listing_example.json)을 함께 저장했다.

| 글자 ID | 글자 | 참여 관계 수 |
| --- | --- | ---: |
| `natal.chart.year.stem` | 乙 | 6 |
| `natal.chart.year.branch` | 亥 | 11 |
| `natal.chart.month.stem` | 辛 | 4 |
| `natal.chart.month.branch` | 巳 | 11 |
| `natal.chart.day.stem` | 癸 | 4 |
| `natal.chart.day.branch` | 卯 | 9 |
| `natal.chart.hour.stem` | 己 | 5 |
| `natal.chart.hour.branch` | 未 | 12 |
| `daewoon.period_2.cycle.stem` | 戊 | 4 |
| `daewoon.period_2.cycle.branch` | 寅 | 8 |
| `sewoon.year_2026.cycle.stem` | 丙 | 4 |

한 관계는 참여하는 각 글자의 목록에 나타난다. 예를 들어 육합이 양쪽 글자에서 보이는 것은 중복 오류가 아니다. 중앙 본문은 관계 ID 하나로 보관된다. 다자 관계는 세 글자 이상에 연결될 수 있으므로 두 글자 관계로 잘라 재조립하지 않는다.

## 화면에서 사용하는 기준과 제공하지 않는 범위

- 원국 선택은 /character-details, 운 선택은 /cycle-analysis 응답의 characters[ID].relation_ids로 중앙 relations를 조회한다. 원국 analysis.relations만 표시하면 운 관계가 빠진다.
- 원국·대운·세운 분류는 상대 글자의 context_id와 관계의 context_ids로 한다. 세 소속이 함께 참여하는 다자 관계는 별도 복합 묶음으로 표시할 수 있다.
- relation_ids의 나열 순서는 중요도·우열·길흉 순위가 아니다. 중요도 순위는 계산하지 않는다.
- 세운 선택 시 해당 대운은 서버가 결정한다. 첫 대운 이전에는 대운 없이 원국+세운으로 제공된다.
- 운 한 기둥 내부의 천간↔지지 관계, 운의 통근, 소속 간 일반 천간↔지지 오행 관계는 현재 제공하지 않는다. 소속 간 투간은 제공한다.
- 운 후보의 실제 성립·경합·세력 영향은 미평가다. 세운은 입춘 시각 구분 없이 달력 연도 기준이다.
- 위 미제공 범위와 등록되지 않은 관계까지 모두 탐지됐다는 뜻은 아니다. 전체 생년월일이나 모든 명리 규칙을 전수 검증한 결과가 아니다.
