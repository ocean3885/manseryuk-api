# 지지 작용 v3 목표·검증표

> **보관 자료 / 중단 연구 기록** — 이 문서의 개발 순서·다음 작업·계수 제안은 현행 지침이 아닙니다. 2026-11-04 기준 자료를 보존하며, 현재 작업은 [현행 문서 목록](../../README.md)을 따릅니다. 명시적 요청 없이 수치 계산·손상률 연구를 재개하지 않습니다.

상태: 2026-11-02의 **시범 검증표**. 관계 규칙의 전수 검증이나 명리 해석의 객관적 정답표가 아니다. [목표 출력 트리](branch_dynamics_v3.json), [공통 관계 계산 구조](branch_relation_engine_design.md), [세력 지표 계약](../../branch_strength_accounting.md)을 실제 원국과 연결한다. 아래 현행 출력은 `.venv312/bin/python`으로 지지 관계 매트릭스 → v2 계산기 → v3 쌍·그룹 조립기를 실행해 확인했다. 현재 API 응답 전체가 v3로 제공된다는 뜻은 아니다.

## 최종 결과가 답해야 할 질문

최종 결과의 중심은 **각 지지의 상태와 지지 사이의 실제 작용**이다. 조화 총점이나 관계별 잠재량의 합계로 원국을 판정하지 않는다.

| 층위 | 최종 결과에 필요한 판단 | 미해결일 때 허용할 출력 | 완료 판단에서 확인할 점 |
| --- | --- | --- | --- |

| 지지별 충 이전 세력 | 월령·지장간·동주 천간·주변 지지·그룹의 출처별 지원/제약, 각 단계의 수치와 계산 상태 | 미계산 구조 기여는 `null`과 사유. 현재 `effective_power`는 잠정 배경 지표로만 표시 | 네 지지를 같은 이름의 숫자 하나로 설명하지 않고, 관계별 `power_before`와 전체 배경값을 구별한다. |

| 방향과 작용 대상 | 원천·대상·저항, 지지 전체와 지장간별 손상/결속/발현 가능성, 각 방향의 근거 | 방향·지장간 대상별 `unresolved`. 잠재 우세를 공격 방향으로 치환하지 않음 | 조합 고정 방향과 원국 구조 의존 방향을 구별한다. 손상·개고·활용 가능성을 한 값으로 합치지 않는다. |
| 지지별 적용 후 상태 | 각 관계의 부호 있는 변화량, 자기 손실, 다중 작용 배분, 최종 잔여 세력과 그 **완성 여부** | 필요한 관계가 미계산이면 최종값 `null`. 확정된 0과 구별 | 작용 후 값이 기준 세력·관계별 변화량과 맞고, 한 출처가 두 번 더해지지 않는다. [목표 출력 트리](branch_dynamics_v3.json)에 필드·상태 계약을 추가했지만 현재 값은 `null / not_calculated`다. |
| 해석·귀속 | 손상 대상의 십신·묘고, 빈위/주위와 천간·합을 통한 귀속 경로, 충제·개고·충괴 등 중심 작용 후보 | 해석 후보와 미확정 사유. 빈주를 세력 가중치로 쓰지 않음 | [작공·LLM 출력](branch_dynamics_v3.json)은 계산 근거 ID를 추적하고 미해결을 확정 사실처럼 서술하지 않는다. |

**완료의 두 수준을 구분한다.** 개발 중에는 근거 없는 방향·손상·수치를 출력하지 않고 미해결 사유를 보존하면 안전하다. 사용자가 원하는 최종 분석 제품으로 인정하려면 검증 사례에서 **방향, 영향을 받은 지지·지장간, 귀속과 지지별 결과**를 상당 부분 재현하거나 명시적으로 설명 가능한 이견으로 남겨야 한다. 모든 사례를 영구히 `unresolved`로 두는 것은 최종 완료가 아니다. 교재 한 건에 계수를 맞춰 같은 결론을 내는 것도 일반화 검증이 아니다.

## 사례의 근거 수준

- **해석 참고(A~D):** [축미충 사례 대조](chouwei_clash_analysis.md)에 출처와 원문 해석을 기록했다. 교재가 서술한 방향·대상·유형만 비교 기준으로 사용한다. 손실률이나 실제 생애 결과의 정답은 없다. 학파 안의 다른 해석 가능성을 배제하지 않는다.
- **변형·경계(E·F·Z1~Z4):** 입력을 통제하거나 여러 충을 겹쳐 **모델의 민감도·수치 범위**를 살핀다. 저자의 해석 정답이 없으므로 자동 방향·유형의 학파 검증으로 세지 않는다. Z3은 천간과 子·午의 위치가 함께 달라 Z1의 단일 변수 대조가 아니다.
- **규칙 회귀(G1~G3·P1·T1·S1):** 사용자와 확정한 탐지·성립·중첩 규칙의 출력 검증이다. 손상량이나 길흉의 정답이 아니다. 근거는 [관계 규칙표](../../mangpa_relation_rulebook.md)와 [성립 판정 기록](../../branch_relation_activation_review.md)이다.

## 검증 통과 규칙과 확장 순서

1. **사실·규칙 검사:** 모든 입력에서 네 지지·여섯 위치 쌍을 보존하고, 후보·성립·억제·ID 참조가 [관계 규칙](../../../services/relation_rules.py)과 일치해야 한다. 위 G·P·T·S 사례의 구조 사실은 자동 회귀 테스트 대상으로 유지한다.
2. **출처·상태 검사:** 지지별 수치가 어떤 단계에서 왔는지 보여야 한다. `active`와 `applied_power_delta`, 계산된 `0`과 미계산 `null`, `effective_power`와 최종 세력을 혼동하면 불합격이다. 같은 출처의 배경·그룹·쌍별 적용량을 한 단계에서 중복 가산하지 않는다.
3. **해석 검사:** A~D에서 방향, 지장간 대상, 충제/개고/충괴, 귀속을 각각 독립적으로 비교한다. 교재가 말하지 않은 손실률에는 정답을 만들어 넣지 않는다. 명시된 해석과 다르면 근거 차이·미계산 단계·대안 해석을 기록하고 전문가가 판정한다.
4. **일반화 검사:** A~D만 맞추는 조합별 예외는 채택하지 않는다. 월간 변경·구조 변경·거리·중복 지지·다중 관계 사례에서 결과가 왜 달라지는지 출처 경로로 설명해야 한다. 별도의 미사용 원국으로 같은 판단 절차를 다시 검토한다.
