# 축미충 A·D: 일반 보정 유지·대체·별도 작용 검토

> **보관 자료 / 중단 연구 기록** — 이 문서의 개발 순서·다음 작업·계수 제안은 현행 지침이 아닙니다. 2026-11-04 기준 자료를 보존하며, 현재 작업은 [현행 문서 목록](../../README.md)을 따릅니다. 명시적 요청 없이 수치 계산·손상률 연구를 재개하지 않습니다.

검토일: 2026-11-02. [전문가 검토 양식](chouwei_expert_review_sheet.md)의 세력 출처 항목에 [선택 출처 진단](../../branch_ambient_replay_audit.md)을 연결한 **개발상 판단과 미확정 해석 목록**이다. 교재 해석에 대한 전문가 승인이나 새 명리 규칙의 확정을 뜻하지 않는다.

## 이번 검토의 결론

1. **현재 계산한 일반 배경은 관측값으로 유지한다.** A의 巳·午→未 일반 生, D의 두 申→丑 일반 설기를 임의로 제거하거나 부호를 바꾸지 않는다. 이는 완성된 구조 모델에서도 반드시 유지한다는 결정이 아니다.
2. **현재 수치에 적용할 대체 경로는 없다.** A의 방합, D의 入墓 모두 기존 일반 보정을 어느 범위까지 대신하는지 입증되지 않았다. 후보의 `replaces_path_ids`는 비운다.
3. **구조 맥락과 지장간 손상은 분리해 검토한다.** 방합·入墓의 성립/가용성 후보와 충에 의한 癸·辛·乙 손상 후보를 서로 다른 단계·대상으로 기록한다. 의미가 구분된다는 이유만으로 런타임 `separate_effect`나 추가 수치를 부여하지 않는다.
4. **丑未의 동기 보정도 최종 계상 문제로 남긴다.** 전체 `effective_power`에는 남고 해당 충의 `power_before`에는 상대가 제외되는 현행 계산 경계를 보존한다. 같은 토라는 이유로 충 후에도 지원이 그대로 남는다고 해석하지 않는다.

계수·실행 규칙·API·v3 스키마를 변경하는 검토가 아니다. 현재 근거로 정할 수 있는 계산 경계와, 해석 근거가 추가되어야 정할 수 있는 결정을 구분한다.

## 유지·대체·별도 작용을 구분하는 기준

| 검토 결과 | 필요한 근거 | 현재 출력 처리 |
| --- | --- | --- |
| 기존 일반 보정 유지 | 해당 출처·대상의 일반 기여가 이미 계산됨. 구조와의 관계가 미정이면 유지 사실도 현행 기준에 한정 | 기존 배경 `include`와 표시값 보존. 최종 집계 확정으로 읽지 않음 |
| 기존 일반 보정 대체 | 같은 대상·기여 범위에서 무엇이 중복되는지, 대체할 정확한 경로 ID, 새 기여의 계산 근거가 모두 확인됨 | 현재 A·D에는 해당 없음. 구조 후보는 `undetermined / null`, `replaces_path_ids: []` |
| 별도 작용 후보 | 대상·작용 단계·결과가 기존 일반 보정과 어떻게 다른지 설명 가능 | 후보의 단계·대상을 구분하되 계상은 `undetermined / null` 유지 |
| 수치가 있는 별도 작용 | 위 구분에 더해 같은 피해/지원의 중복이 없고 변화량 산식·단위·입력 시점이 검증됨 | 이후에만 `separate_effect` 검토. 현재 A·D에는 해당 없음 |

**출처가 같다는 사실만으로 대체할 수 없고, 대상·단계가 다르다는 사실만으로 독립 가산할 수도 없다.** 같은 출처가 세력 지원과 피해 원인을 함께 설명할 수 있지만, 하나의 에너지를 두 번 가산하거나 하나의 손상을 두 번 차감하는지 별도 확인해야 한다. `overlaps_path_ids`는 이 검토 지점의 표시다.

## A: `乙己己庚 / 巳丑未午`

### 일반 배경에 대한 대상별 판단

아래 비율은 [현행 계산 관측](chouwei_a_d_source_paths.md)의 표시값이다. `path:background:<출처>:<대상>:branch`가 실제 중앙 경로 ID다.

| 출처 → 대상 | 경로 ID | 현행 비율·계상 | 이번 판단과 한계 |
| --- | --- | --- | --- |
| 연 巳 → 일 未 | `path:background:year:day:branch` | `+0.028735 / include` | 현재 일반 生 보정 유지. 방합이 같은 기여를 재표현하는지는 미정 |
| 시 午 → 일 未 | `path:background:hour:day:branch` | `+0.038133 / include` | 현재 일반 生 보정 유지. 午未합 `conditional`만으로 제거하지 않음 |
| 월 丑 → 일 未 | `path:background:month:day:branch` | `+0.034131 / include` | 전체 배경에서는 유지. 丑未충의 기준 세력에서는 충 상대이므로 제외됨 |
| 연 巳 → 월 丑 | `path:background:year:month:branch` | `+0.041050 / include` | 현재 일반 生 보정 유지. 巳午未가 월 丑에도 같은 방향의 지원이라는 결론은 아님 |
| 시 午 → 월 丑 | `path:background:hour:month:branch` | `0 / exclude` | 활성 丑午천에 따른 기존 일반 生 억제 유지. 천 자체의 영향은 미계산 |
| 일 未 → 월 丑 | `path:background:day:month:branch` | `+0.031088 / include` | 전체 배경에서는 유지. 丑未충의 기준 세력에서는 상대 제외. 최종 지원/손상 계상은 미정 |

### 구조·피해 후보에 대한 판단

| 검토 대상 | 이미 계산된 부분과의 관계 | 이번 판단 | 대체·독립 작용을 정하려면 필요한 것 |
| --- | --- | --- | --- |
| 巳午未 구조 → 일 未 | 그룹 경로 `path:group:formation:square:year:day:hour:day:branch`는 巳·午→未 두 일반 배경과 겹침을 기록 | `potential` 구조의 수치는 미정. 일반 生을 유지하며 그룹 후보에 수치를 더하지 않음 | 일반 生의 재표현인지, 未 전체 세력의 추가 변화인지, 특정 지장간의 가용성 변화인지 구분한 사례 근거 |
| 丑午천 → 월 丑 | 午→丑 일반 生은 이미 0. 구조 영향까지 0인 것은 아님 | 기존 억제 유지, 천의 독립 영향은 보류 | 천이 丑 전체/특정 지장간 중 무엇을 바꾸는지와 丑未충 손상과의 중복 여부 |
| 일 未 → 월 丑 속 癸·辛 | 교재가 지목한 피해 대상. 巳·午→未의 일반 生과 대상·단계가 다름 | 癸·辛 각각의 **충 손상 후보**로 검토. 손상량·계상 방식은 미정 | 未가 주도하는 조건, 癸와 辛 각각의 손상 경로, 己가 같은 피해로 묶이지 않는 이유 |
| 午未합 → 未 속 乙 폐쇄 | 현재 합이 `conditional`, 폐쇄는 `candidate_only` | 실제 폐쇄나 손상을 확정하지 않음 | 합 성립 조건과 폐쇄의 연결, 방합·충과의 경합 근거 |

선택 진단에서 일 未는 전체 배경 `1.8098`, 巳만 생략 `1.7626`, 巳·午 생략 `1.6999`다. 마지막 값에도 월 丑의 동기 보정은 남는다. **`1.6999`는 방합으로 대체한 未의 세력이 아니다.** 巳·午의 일반 보정을 생략했을 뿐 새 구조 기여를 계산하지 않았다. 또한 이 세 값은 충 상대 丑을 제외한 해당 충의 `power_before=1.7537`과 계산 범위가 다르다.

교재의 未→丑 방향에 맞추려고 未에 배율을 부여하지 않는다. A는 현재 **방향과 피해 원인의 자동 재현이 보류된 사례**다.

## D: `庚己丙乙 / 申丑申未`

### 일반 배경에 대한 대상별 판단

| 출처 → 대상 | 경로 ID | 현행 비율·계상 | 이번 판단과 한계 |
| --- | --- | --- | --- |
| 연 申 → 월 丑 | `path:background:year:month:branch` | `−0.031722 / include` | 현재 일반 설기 보정 유지. 入墓의 강화/약화를 계산한 수치가 아님 |
| 일 申 → 월 丑 | `path:background:day:month:branch` | `−0.035254 / include` | 연 申과 별도 출처로 유지. 같은 글자라는 이유로 합치거나 고정 두 배로 바꾸지 않음 |
| 시 未 → 월 丑 | `path:background:hour:month:branch` | `+0.017484 / include` | 전체 배경에서는 유지, 丑未충의 기준 세력에서는 상대 제외 |
| 연 申 → 시 未 | `path:background:year:hour:branch` | `−0.015861 / include` | 월 丑 대상의 入墓 후보가 이 경로까지 대신한다고 확대하지 않음 |
| 일 申 → 시 未 | `path:background:day:hour:branch` | `−0.035254 / include` | 현재 일반 설기 보정 유지. 未 속 乙 손상량으로 읽지 않음 |
| 월 丑 → 시 未 | `path:background:month:hour:branch` | `+0.023891 / include` | 전체 배경에서는 유지, 해당 충에서는 상대 제외. 충제와 최종 계상 관계는 미정 |

### 구조·피해 후보에 대한 판단

| 검토 대상 | 이미 계산된 부분과의 관계 | 이번 판단 | 대체·독립 작용을 정하려면 필요한 것 |
| --- | --- | --- | --- |
| 연·일 申 → 월 丑의 入墓·창고 연결 | 교재 참고 경로. 두 申→丑 일반 보정과 출처가 겹치지만 기여 대상·의미의 일치는 미확인 | 자동 탐지되지 않는 검토 후보. `overlaps`만 기록하고 두 음의 보정을 제거/양수 전환하지 않음 | 입묘의 대상이 丑 전체인지 창고 기능/특정 지장간인지, 사용 가능성과 전체 세력 증감의 관계 |
| 두 申의 구조망 | 두 위치별 일반 경로는 존재하지만 독립된 구조 효과가 두 건인지는 미확인 | 위치 정보는 둘 다 보존. 검토 후보망은 한 묶음으로 표현 가능하나 수치 집계 단위는 보류 | 申 하나를 바꾸거나 제거한 비교 사례, 두 출처의 독립성·공유 기전 |
| 월 丑 → 시 未 속 乙 | 교재가 지목한 충제 대상. 시 未 전체의 설기나 동주 乙 보정과 동일한 항목이 아님 | 乙 손상 후보는 별도 대상으로 기록, 계상은 미정 | 丑의 주도 조건, 入墓와의 의존이 필수인지 참고 설명인지, 같은 손상을 다른 경로에서 이미 계산했는지 |

선택 진단에서 월 丑은 전체 `2.0443`, 연 申 생략 `2.1125`, 일 申 생략 `2.1201`이다. 이는 기존 음의 설기 보정을 하나씩 생략한 결과다. **값이 커졌다는 이유로 入墓가 丑을 강화한다고 판정하지 않는다.** 충 상대 未를 제외한 `power_before=2.0067`도 별도 비교 범위다.

D는 현재 **주도 방향의 대소가 교재와 같지만 그 원인은 재현되지 않은 사례**다. A와 달리 방향만 맞는다는 이유로 검증 완료 사례로 집계하지 않는다.

## 다음 구현에 적용할 경계

### 지금 정할 수 있는 것

- 기존 일반 경로의 값·ID·차단은 보존한다. 구조 후보의 겹침을 자동 대체 명령으로 사용하지 않는다.
- 지장간 손상 후보는 지지 전체 세력과 분리된 대상으로 기록한다. 숨은 글자의 피해량을 전체 세력의 변화량으로 직접 합산하지 않는다.
- 교재 A의 癸·辛, D의 乙과 入墓 설명은 **사례 범위의 검토 자료**로 보존한다. 생산 규칙에 모든 丑未충의 고정 방향·피해 대상으로 넣지 않는다.
- 같은 오행의 동기 보정과 충 손상 간 계상은 후속 검토 항목이다. 현재 사용자 결정인 일반 生·극 억제를 동기 전체 억제로 확대하지 않는다.

### 다음에 만들 최소 구현

[기존 외부 후보 입력](../../../services/branch_influence_paths.py)을 이용해 **사례별 검토 자료**를 먼저 구성한다. 새 조합별 계산기를 만들지 않는다.

| 범위 | 포함할 자료 | 완료 기준 |
| --- | --- | --- |
| A | 丑 속 癸·辛 각각의 피해 후보와 교재 A 근거. 자동 탐지된 방합 경로와 연결 가능한 참조 | 실제 丑 지장간만 가리키고 방향은 교재 주장으로 한정. 방합과의 필수 의존은 근거 없이 확정하지 않음 |
| D | 두 申 위치를 보존한 入墓 검토 후보, 未 속 乙 피해 후보와 교재 D 근거 | 검토 후보를 넣었을 때만 나타남. 入墓→乙 손상의 의존 관계는 교재 해석/가설의 범위로 명시 |
| 공통 | `source_interpretation`, `undetermined`, `quantity: null`, `replaces_path_ids: []` | 근거 없는 수치·자동 대체·잘못된 지장간·없는 관계 참조를 거부하고, 원본 세력과 생산 출력에 변화 없음 |

여기서 入墓의 일반 성립 규칙이나 피해율은 구현하지 않는다. 검토 자료가 갖춰진 뒤 전문가가 **대상·기전·경합·반례 조건**을 확정한 범위만 [관계 규칙](../../../services/relation_rules.py)과 공통 평가기로 옮긴다.

- 이번 산출물은 계상 검토 문서다. 교재 해석의 타당성, 손상량 또는 새 규칙의 정확도를 위 테스트가 검증한 것은 아니다.
