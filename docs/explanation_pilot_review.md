## 제품 적용 제안

1. 상세 근거 아래 선택적으로 여는 학습 해설로 먼저 검토한다. 개인 종합 해석이나 관계 우선순위 판단의 용도로 사용하지 않는다.
2. 관계 유형 설명과 십성 용어 설명을 공통으로 제공하고, 두 설명을 연결할 실질적인 내용이 있는 패턴에만 개별 해설을 둔다. 반복적인 주의 문구는 공통 UI로 옮기는 방안을 검토한다.
3. 방향 유무, 일간 참여, 합의 존재와 성립의 구분, 동주 본기와 자합 지장간의 구분을 작성 가이드에 명시한다. 현재 파일은 기존 가이드의 문제를 보기 위한 결과이므로 가이드를 소급 변경하지 않았다.
4. 자합 개별 해설은 실제 참여 지장간 정보가 충분한지 먼저 검토한다. 현재 패턴을 자동 확장하거나 판정 규칙을 바꾸지는 않는다.
5. 다음 검토는 위 원문·수정문 2~3쌍을 사용자에게 보여 주고 추가 이해와 읽기 부담을 확인한다. 실제 화면·이용자 반응 확인 전 서비스 가치가 입증됐다고 판단하지 않는다.
