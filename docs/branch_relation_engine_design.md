# 지지 관계 계산 구조 설계

상태: 구조 제안. 기존 계산값·API 계약을 변경하지 않는다. 관계별 손실식과 계수는 사례 검증 전까지 확대하지 않는다.

## 목표와 현행 경계

목표는 원국의 각 지지에 대한 **근거가 추적되는 충 이전 세력**을 마련하고, 합·충·천·파·형의 성립·방향·작용 대상을 판정하는 것이다. 십신·빈주는 작용 결과의 해석에 사용하며 세력 산식에 넣지 않는다. 수치가 미검증인 경우 후보와 근거는 출력하되 적용량은 `null`로 둔다.

| 관심사 | 현행 위치 | 설계상 책임 |
| --- | --- | --- |
| 어떤 글자 조합이 어떤 관계 후보인지 | [관계 규칙](../services/relation_rules.py)의 `CHUNGS`, `CHEONS`, `BREAKS`, `PUNISHMENTS`, 합·그룹 표 | 후보 정의. 위치·원국마다 달라지는 주도권은 보관하지 않는다. |
| 조합별 방향·기전·잠정 계수 | [관계 규칙](../services/relation_rules.py)의 `PAIR_ACTION_RULES`; 일부 조합에만 값이 있음 | 검증된 조합별 제약과 예외만 둔다. 미기재 쌍을 기본 수치로 자동 채우지 않는다. |
| 기준 세력과 주변 영향 | [지지 계산기](../services/branch_dynamics.py)의 `_branch_strength`, `_context_power` | 월령·동주 천간·주변 지지의 기여를 출처별로 기록한다. 구조 관계의 독립 기여가 미정이면 세력 결과도 잠정임을 표시한다. |
| 잠재 작용과 출력 조립 | [v3 조립기](../services/branch_dynamics_v3_assembler.py)의 `_directional_metrics`, `assemble_branch_pairs_v3` | 규칙과 계산 결과를 출력 계약으로 변환한다. 조합별 계산을 이 함수 안에 계속 추가하지 않는다. |
| 실제 적용량 | 현재 [子午충 계산기](../services/branch_clash_effects.py)의 `ziwu_loss_rates`, `allocate_branch_losses`와 v3 조립기의 `ziwu` 분기 | 검증된 계산 모델을 선택해 실행하고, 같은 지지가 여러 작용을 받으면 출처별로 한 번만 집계한다. 현재는 子午충만 잠정 모델이 있다. |

## 세 수준으로 규칙을 나눈다

| 수준 | 모든 관계에 공유하는 것 | 합·충·천·파·형별로 달라지는 것 | 조합별로만 둘 것 |
| --- | --- | --- | --- |
| 후보·성립 | 위치 쌍과 그룹 탐지, 관계 ID, 거리, 성립 근거 | 예: 육합의 충 개입, 자형의 인접 조건, 삼형의 세 글자 조건 | 후보 조합, 명시적으로 검토한 추가 성립 조건 |
| 세력 | 월령·지장간 비율·동주 천간·주변 지지의 출처별 기여 | 구조가 주변 생극을 대체하거나 지원을 묶는 방식. 독립량이 미정이면 유보 | 검증된 지장간 특성이나 특정 구조의 귀속 제약 |
| 방향·역할 | 두 지지의 충 이전 세력, 원천·대상·저항, 동률·유보 | 충의 공격·저항, 합의 결속·견인, 천·파·형의 손상 또는 구조 변화 모델 | 子午의 子→午처럼 확인된 고정 방향; 丑未처럼 구조 비교가 필요한 경우의 제한 조건 |
| 작용 대상 | 지지 전체와 지장간별 상태를 구분 | 결속, 손상, 발현, 압박 등 허용할 결과 종류 | 문헌·사례로 확인된 대상 후보. 후보를 실제 손상으로 단정하지 않음 |
| 수치·집계 | 잠재량과 적용량 분리, 동일 출처 중복 방지, 반올림·상한 | 관계 유형별 **검증된** 계산 모델. 검증 전 `pending` 또는 `potential_calculated` | 공통 모델로 설명되지 않는 사례가 반복 확인될 때만 예외 모델과 보정 버전 |
| 해석 | 역할·손상 대상을 십신·빈주·묘고에 연결 | 충제·개고·충괴 등 유형 후보와 판정 유보 | 원국별 귀속 경로. 조합만으로 길흉을 고정하지 않음 |

이 표의 '관계 유형별 계산 모델'은 **계획된 확장 지점**이다. 현재 충 전체, 또는 다른 관계 전체에 재사용할 실측 손실식이 확정됐다는 뜻이 아니다. 예외를 넣기 전에 공통 모델이 어떤 사례에서 실패하는지 먼저 기록한다.

## 공통 처리 순서

1. **후보 탐지:** 원국의 여섯 위치 쌍과 그룹 후보를 모두 기록한다.
2. **성립 판정:** 존재·인접·충 개입 등 규칙으로 `active`, `conditional`, `suppressed` 등을 정한다. `active`는 작용량 확정을 뜻하지 않는다.
3. **충 이전 세력 산정:** 월령과 동주 천간을 먼저 반영하고 주변 지지와 그룹 지원을 출처별로 추적한다. 같은 출처의 생극·합·방합을 별도로 더하지 않는다. 미계산 구조 기여를 숫자 0으로 간주하지 않는다.
4. **방향·대상 판정:** 관계 종류와 조합별 방향 제약을 적용하되, 원국의 세력·지원·저항이 필요한 경우는 비교 결과를 기다린다. 지지 전체의 우세를 모든 지장간의 손상으로 바꾸지 않는다.
5. **적용량 계산:** 해당 관계에 검증된 모델과 입력이 모두 있을 때만 손실·강화량을 계산한다. 같은 지지의 다중 작용은 출처 ID로 집계한다. 그 밖에는 잠재 지표와 미해결 사유를 남긴다.
6. **결과 해석·출력:** 손상·발현·귀속을 분리한 뒤 십신·빈주 맥락을 붙인다. 충제·개고·충괴 등은 근거가 충족될 때만 중심 작용으로 분류한다.

세력 계산과 관계 효과가 서로를 참조하는 순환을 피하기 위해 3단계의 **충 이전 세력**과 5단계의 **작용 후 변화량**을 별도 상태로 둔다. 5단계의 결과를 같은 계산 차례의 3단계 입력으로 되돌리지 않는다. 여러 구조가 경합할 때의 우선순위는 독립적으로 검증해야 하며, 임의 순서로 먼저 계산한 관계가 뒤 관계를 바꾸지 않게 한다.

## 데이터로 둘 것과 코드로 둘 것

- 데이터: 조합 목록, 성립 조건의 식별자, 고정된 방향 제약, 지장간 대상 **후보**, 근거 문헌·사례 ID, 모델 ID, 보정 버전과 검증 상태. [관계 규칙](../services/relation_rules.py)의 기존 단일 원본을 유지한다.
- 코드: 세력 기여의 출처 추적, 조건 평가, 모델 선택, 수치 계산, 중복 방지, 상태 전파, 출력 검증. 조합 이름별 `if` 분기를 [v3 조립기](../services/branch_dynamics_v3_assembler.py)에 누적하지 않는다.
- 데이터에 임의 Python 함수나 복잡한 조건식을 넣지 않는다. 새로운 조건이나 계산 방식이 필요한 경우 이름이 있는 평가기·모델을 구현하고 규칙에서 그 ID를 참조한다. 어떤 ID가 무슨 입력을 요구하는지도 검사한다.
- 규칙 미기재, 모델 미구현, 입력 부족, 완전 차단을 서로 다른 상태로 기록한다. **미기재 = 계수 1.0**, **미계산 = 적용량 0** 같은 기본값은 두지 않는다.

### 두 충의 적용 예

| 관계 | 후보·성립 | 방향 제약 | 구조 입력과 현재 계산 상태 |
| --- | --- | --- | --- |
| 子午충 | 두 지지가 있으면 `active`; 거리는 강도 근거 | 子→午, 子의 자기 손실 가능성을 별도 기록 | [잠정 子午 식](./ziwu_clash_effect_design.md)은 午 충격과 子 자기 손실을 계산하지만, 계수·기준 세력 검증이 남아 `provisional_calculated`다. |
| 丑未충 | 두 지지가 있으면 `active`; 거리·위치 기록 | 고정 공격자 없음. 양쪽의 구조 지원과 지장간 상태 비교 필요 | [사례 대조](./chouwei_clash_analysis.md)에서 현행 쌍별 세력만으로 未→丑 사례를 재현하지 못했다. 적용 손실량·충제/개고/충괴 자동 판정은 `pending`이다. |

## 구현을 시작할 때의 순서와 확인 기준

1. **세력 지표·출처 계약:** 현행 `effective_power`, 관계별 `power_before`, 최종 작용 후 세력의 의미를 [지지 세력 지표와 기여 출처 계약](./branch_strength_accounting.md)에 기록했다. [방합 내부 장부](./branch_group_source_ledger.md)와 [A·D 출처 추적](./chouwei_a_d_source_paths.md)을 바탕으로 [출처 경로 최소 자료 구조](./branch_influence_path_contract.md)를 제안하고 내부 자료형·검증기를 구현했다. 현재 출력에 연결하기 전까지 일반 보정의 재계산이나 구조 수치화는 하지 않는다.
2. **사례 대조표:** 원국·관계·문헌의 방향/대상/유형 판단, 현행 출력, 불일치 원인을 분리해 기록한다. 판단이 없는 시험 입력은 정답으로 취급하지 않는다.
3. **공통 모델 경계 추출:** 적용량을 계산하는 전략의 입력·출력 계약을 만든다. 처음에는 현재 子午 잠정식만 전략으로 옮겨 출력이 동일한지 확인한다. 다른 쌍에 이 식을 자동 적용하지 않는다.
4. **관계 유형별 확장:** 사례가 쌓인 뒤 충의 일반 모델을 시험하고, 이어 합·천·파·형을 검토한다. 일반 모델이 특정 조합을 설명하지 못할 때 근거가 있는 예외만 추가한다.

완료 기준은 새 조합 하나를 추가할 때 **규칙 데이터와 사례 검증은 늘어도 조립기의 조합별 분기는 늘어나지 않는 것**이다. 동시에 계산할 근거가 없는 관계는 그 사실이 출력에서 드러나야 한다.
