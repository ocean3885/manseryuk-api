# 지지 작용 분석 v2: 첫 구현 기준

> 관계별 후보·활성 조건은 [맹파 지지·간지 관계 규칙표 초안](./mangpa_relation_rulebook.md)에서 재검토 중이다. 子午·子卯·卯午·午酉·辰酉와 조건부 자합을 먼저 반영했다. 남은 관계의 점수식은 여전히 실험값이다.

실행 규칙과 실험 계수의 단일 원본은 [`services/relation_rules.py`](../services/relation_rules.py)이다.

## 목표

원국의 네 지지가 서로 맺는 합·충·형·파·천과 오행의 생·극을 식별하고, **각 관계에서 어느 지지가 얼마나 작용하고 영향을 받는지** 근거와 함께 반환한다. 빈(년·월)과 주(일·시)는 결과를 읽는 보조 분류다. 계산의 중심은 빈주 점수나 길흉 예측이 아니다.

이 문서는 초기 구현의 계산 계약과 한계를 기록한다. 숫자는 명리학적 절대량이 아니라 **버전 2.19.0의 미보정 상대 지표**다. 규칙 계수를 바꾸면 버전도 변경한다.

## 먼저 구분할 개념

1. **지지별 기초 세력**: 지장간 구성과 월령을 반영한, 지지 간 관계 이전의 값. 네 지지를 같은 척도로 비교할 수 있어야 한다.
2. **동주 천간의 작용**: 각 지지 위에 놓인 천간이 그 지지를 생하는지, 극하는지, 같은 오행인지, 또는 지지가 천간을 생·극하는지를 판정한다. 특히 월지의 세력은 월간을 확인한 뒤 지지 간 관계에 투입한다. 천간 투출·통근의 효과도 이 단계에서 별도로 확인한다.
3. **관계의 성립**: 합·충·형·파·천과 생·극을 각각 독립적으로 판정한다. 한 쌍에 여러 관계가 동시에 있을 수 있다. 삼합·방합은 두 지지 관계로 분해하지 않고 다자 관계로 보존한다.
4. **관계별 작용량**: 관계 종류, 동주 천간 작용까지 반영한 양쪽 세력, 거리, 성립 조건을 이용해 양방향 작용량과 영향량을 계산한다. 관계가 있다는 사실과 한쪽이 우세하다는 판정은 별개다.
5. **해석 방향**: 오행상 생·극의 방향, 상대 세력 우세, 합의 견인·충의 충격 같은 해석을 각각 표시한다. 오행상 정해진 생·극 방향은 세력 우세가 바뀌어도 뒤집지 않는다. 우세만으로 현실 결과나 길흉을 확정하지 않는다.

### 동주 천간 판정의 최소 범위

| 천간과 지지의 오행 관계 | 지지 입장의 1차 판정 | 수치 반영 전 확인할 점 |
| --- | --- | --- |
| 천간이 지지를 생함 | 지원받음 | 천간의 유효 세력과 지장간 구성 |
| 천간이 지지를 극함 | 제약받음 | 지지의 저항력과 지장간별 반응 |
| 지지가 천간을 생함 | 천간으로 기운을 보냄 | 실제 지지 세력의 소모량을 별도 규칙으로 정함 |
| 지지가 천간을 극함 | 천간에 작용함 | 지지가 반드시 약해진다고 가정하지 않음 |
| 같은 오행 | 동질 관계 | 강화량을 자동 확정하지 않음 |

지지는 지장간이 혼합된 구조이므로 지지의 대표 오행 하나만으로 최종 증감을 확정하지 않는다. 우선 본기 기준의 방향을 기록하고 지장간별 비율·투출 여부를 근거로 함께 출력한다. 월간이 월지를 직접 극하는 경우와 월지가 월간을 생해 힘을 내보내는 경우는 모두 세력 변화 가능성이 있지만 **서로 다른 원인**으로 기록한다. 월령의 계절 효과와 월간의 작용은 별도 항목이며, 같은 지원을 중복 가산하지 않는다.

## 현재 구현된 계산

- `base_power = 위치 가중치 × Σ(지장간 비율 × 월령 관계 계수)`. 위치 가중치는 기존 코드의 년 1.0, 월 2.0, 일 1.5, 시 1.0이다. 월령 관계 계수는 같은 오행 1.20, 월령이 생함 1.10, 월령을 생함 0.90, 월령이 극함 0.80, 월령을 극함 0.95다.
- `after_stem_power = base_power × (1 + Σ(지장간 비율 × 동주 천간 관계 계수))`. 동주 천간이 지장간을 생함 +0.20, 극함 -0.25, 지장간이 천간을 생함 -0.15, 극함 -0.05, 같은 오행 +0.10이다. 본기 기준 관계와 지장간별 내역을 함께 반환한다.
- 다른 지지의 배경 효과는 그 지지의 `after_stem_power`와 거리를 이용한다. 동일 오행 +0.05, 원천 지지가 대상 지지를 생함 +0.08, 대상이 원천을 생함 -0.06, 원천이 대상을 극함 -0.10, 대상이 원천을 극함 -0.03의 조정률을 사용한다. 이 조정률의 합은 ±0.35로 제한한다. `effective_power`는 모든 다른 지지를 반영한 개괄 값이다.
- 각 `ambient_evidence`에는 `element_relation_id`와 그 쌍의 `related_relations`를 함께 둔다. `activation_status`는 **생·극 배경 작용 자체**의 상태이고, `related_relations[].activation_status`는 합·충·형 등 **별개 관계**의 상태다. 명시적인 생·극 규칙이 `suppressed` 또는 `conditional`이면 그 배경 보정을 0으로 둔다. 합 후보만 유보되었다는 이유로 생·극까지 자동 억제하지 않는다. 예를 들어 `申寅亥子`의 寅亥 육합은 `conditional`이지만 亥→寅 생의 배경 보정은 유지한다. 파·충이 `active`인 같은 쌍의 생·극은 `suppressed`, 주변 보정 0으로 처리한다. 다른 위치 쌍의 생·극에는 이 억제를 전파하지 않는다.
- **관계별** `power_before`는 비교하는 상대 지지의 배경 효과를 제외한 값이다. 자기 관계의 효과로 세력이 먼저 바뀌고, 그 바뀐 세력으로 같은 관계의 승패를 재판정하는 순환을 피하기 위해서다. `context_evidence`에 반영된 다른 기둥을 남긴다.
- `force`는 `power_before × 거리 가중치 × 방향별 관계 계수`로 계산한 관계별 잠재 작용량이다. 거리 가중치는 인접 1.0, 한 칸 건너 0.7, 두 칸 건너 0.5다. 미정의 조합의 기본 계수는 육합 1.00, 반합 0.70, 충 1.00, 형 0.75, 파 0.45, 천 0.65, 생 0.60, 극 0.80이다. 조합별 계수가 있으면 `directional_coefficients`를 적용한다. 생·극은 오행상 작용 방향의 값만 기록하고 반대 방향은 0으로 둔다. 子卯는 파로만 기록하며, 파·충이 `active`인 쌍의 생·극은 후보를 보존하고 `suppressed`로 표시한다. `effect_received`는 상대의 작용량에 `상대 세력 / 두 세력 합계`를 곱한 모델 지표다. 관계 유형별 작용량은 서로 더하지 않는다.
- `dominance`는 두 `power_before`의 차이가 합계의 10%를 넘을 때만 강한 위치로 표시한다. 이 값은 세력 우세이며 생·극의 오행 방향과 별개다.
- `force_dominance`는 해당 관계의 양방향 `force`를 같은 10% 허용치로 비교한다. 두 방향 모두 0이면 `undetermined`이고 비슷하면 `tie`다. 예를 들어 `子寅午辰`의 子→寅 생에서는 월지 寅의 관계 전 세력이 더 커 `dominance=month`이지만, 생 작용 방향은 년지 子에서 월지 寅으로만 향하므로 `force_dominance=year`다. 이 값은 관계별 작용의 방향 우세이며 지지 자체의 우열이나 실제 사건의 승패가 아니다.
- `roles`는 **관계별 잠재 작용량을 읽기 위한 분류**다. 합은 작용량이 큰 쪽을 `leads_attraction`, 상대를 `drawn_more`로, 충·형·파·천는 `delivers_more_pressure`와 `receives_more_pressure`로 표시한다. 생·극은 오행상 정해진 방향을 따라 `supports`/`receives_support`, `controls`/`receives_control`로 구분한다. 양방향 힘이 비슷하면 합은 `mutual_attraction`, 압박 관계는 `mutual_pressure`이며, 작용량이 모두 0이면 양쪽 모두 `inactive`다. 강도 비교와 역할 분류는 이 프로젝트의 잠정 규칙이며 실제 피해·합화·길흉을 확정하지 않는다.
- 삼합·방합의 `formation_evidence[]`는 **실제 성립 조합별** 참여 위치(`pillars`), 글자의 구조적 자리(`structural_roles`), `power_before`, 조합 내부 상대를 제외한 `context_evidence`, 조합 안에서의 상대 세력 비중(`capacity_share`), 포함된 육합·반합(`overlapping_pairs`)을 반환한다. `power_before`는 지장간·월령·동주 천간과 조합 **밖** 지지의 배경 보정을 반영한다. `capacity_share`는 이 세력값을 한 조합 안에서 나눈 비율이며 그룹의 실제 견인력이나 지지별 세력 증가분이 아니다. 같은 글자가 다른 위치에 반복되어 성립 조합이 여럿이면 비중도 조합별로 각각 계산한다. `overlapping_pairs[].covered_in_harmony_score`는 기존 조화 점수의 중복 집계 여부를 설명할 뿐 지지별 작용량 차감 규칙은 아니다. 그룹 `status`는 아직 `not_scored`이며, 조합별 비중을 쌍별 `force`나 `effective_power`에 더하지 않는다. 억제된 삼합의 잔존 반합은 별도 쌍 관계로 유지한다.
- 그룹의 `action_rule_id`는 조합별 방향 후보 규칙을 가리킨다. 삼합의 `directional_candidates`는 생지·묘고에서 중신으로 모이는 **구조상 경로**이고, 寅午戌 묘고의 `center_generates_storage_candidate`와 다른 삼합 묘고의 `transformation_candidate`는 별도 효과 후보다. `candidate_only`는 방향별 힘을 계산했다는 뜻이 아니다. 방합은 `direction_status: undetermined`와 빈 방향 후보 목록을 낸다. 그룹이 억제·유보되면 그 상태가 후보에도 붙는다. `pair_overlap_policy: preserve_pair_do_not_sum_group_force`는 탐지된 육합·반합의 쌍별 힘을 유지하고 그룹 힘을 합산하지 않는 정책이다. 완성 삼합의 내부 반합은 별도 사건·힘으로 출력하지 않고 구성 근거로만 취급하며, 삼합이 깨져 남은 반합은 독립 쌍 관계로 출력한다. 방합에도 독립 힘을 부여하지 않는다. 따라서 그룹 `status`는 `not_scored`이고 실제 견인·합화는 확정하지 않는다.

이 계수는 해석 모델의 첫 가정이며 경험적 피해량이나 길흉 확률로 검증된 값이 아니다. 관계 유형별 피해·견인 계수, 다자 관계의 작용량, 천간의 사주 전체 세력에 따른 동주 작용 보정은 다음 단계의 검증 대상이다.

## 산식 설계 순서

1. 지장간 비율과 월령을 이용한 **기초 세력**의 척도와 정규화 범위를 정한다. 월지 위치 가중치와 계절 보정을 이중 적용하지 않는다.
2. **동주 천간-지지 작용을 지지 간 작용보다 먼저 계산한다.** 월간이 월지를 생·극하는지, 월지가 월간을 생·극하는지와 투출·통근의 효과를 구별한다. 동주 천간의 유효 세력 평가에 해당 지지의 통근 점수를 사용할 경우, 그 결과를 다시 지지의 원점수에 무한히 되먹이지 않도록 계산 순서를 고정한다.
3. 다른 지지의 생·극 지원·압박, 합·충·형·파·천 효과 중 어떤 것을 **유효 세력**에 반영할지 정한다. 쌍의 결과가 다시 자기 세력의 입력으로 돌아가는 순환 계산은 피하거나 반복 계산 규칙을 명시한다.
4. 관계별 양방향 작용량 산식을 정한다. 합의 견인, 충의 충격, 형·파·천의 영향, 생·극의 지원·제약은 동일한 이름의 단일 점수로 합산하지 않는다.
5. 우세 판정의 동률 범위를 정한다. 차이가 작거나 규칙상 방향을 정할 수 없으면 `tie` 또는 `undetermined`를 반환한다.
6. 같은 쌍의 중첩 관계와 삼합·방합 참여가 힘을 중복 증폭하지 않도록 적용 순서와 상한을 정한다.

산식의 각 계수에는 의미, 근거, 버전을 부여한다. 점수는 모델 내부의 상대 지표로 설명하고 현실 성취·피해의 크기로 해석하지 않는다.

| 월지 卯에 월간 癸·辛·丁을 각각 놓은 합법적인 간지 사례 | 월간→월지 생, 월간→월지 극, 월지→월간 생을 서로 다른 근거로 구분한다. 지지 간 관계 탐지 결과 자체는 유지된다. |
| 같은 월지와 월간에 지장간 투출·다른 천간 조건만 변경 | 동주 관계의 종류와 수치 보정 근거를 분리하고 중복 가산하지 않는다. |
| 년지 子–일지 午, 위치를 서로 바꾼 사례 | 충은 양쪽 모두 탐지된다. 오행의 극 방향은 위치에 따라 바뀌며, 관계별 작용량은 양쪽 모두 출력된다. |
| 같은 충 관계에 월령·지원 조건만 다른 두 원국 | 관계 종류는 유지되고 기초 세력과 우세 판정은 원국 조건에 따라 달라질 수 있다. |
| 충과 생·극이 같은 쌍에 성립 | 관계들을 보존하고 각 의미를 구분한다. |
| 파 또는 해만 성립 | 빈주 영역 여부에 관계없이 관계가 사라지지 않는다. |
| 합과 충이 동시에 존재 | 합·충의 개별 근거를 남기고 하나의 상쇄 점수로 요약하지 않는다. |
| 삼합·방합에 반복 지지가 참여 | 실제 참여 위치를 보존하고 쌍별 작용량과 다자 작용량을 혼동하지 않는다. |
| 세력 차이가 판정 허용치 이내 | 일방 승패를 강제하지 않는다. |

## 기존 응답과의 관계

현재 `interactions.matrix`의 `relation_id`를 새 작용 결과의 원본 참조로 유지한다. 기존 `five_elements.scores`는 오행 합계, `xu_shi_dynamics`의 점수는 천간 통근·허실 규칙의 결과이므로 지지별 세력으로 직접 재사용하지 않는다.

### 빈주 정보의 통합 방향 (목표 계약, 아직 미구현)

최신 목표 JSON 트리는 [사용자 v3 설계 샘플](./branch_dynamics_v3.json), 단계별 구현 순서는 [v3 개발 계획](./branch_dynamics_v3_plan.md)에 기록한다. [이전 출력 계약 초안](./branch_dynamics_target_contract.md)은 비교 자료로 남긴다.

빈주(년·월=빈, 일·시=주)는 지지 작용의 **해석 맥락**으로 각 결과에 연결한다. 지지 관계의 존재·성립·방향·힘을 빈주 구분이나 기존 빈주 총점으로 결정하지 않는다. 현재 `pairwise[].domain_pair`는 빈–빈·주–주·빈–주 분류를 제공한다. 목표 계약에서는 `branch_strengths.<pillar>`에 해당 지지의 빈·주 영역을, `pairwise[].relations[]`에 이미 계산된 작용 방향을 영역 관점에서 읽는 근거를, `groups[].formation_evidence[]`에 참여 위치별 영역과 영역 사이 연결 여부를 배치한다. 정확한 필드명과 자료형은 출력 트리 설계 단계에서 확정한다.

| 기존 `bin_zhu_dynamics` 내용 | 목표 위치·처리 |
| --- | --- |
| `guest_structure`·`host_structure`의 **지지 위치** | `branch_strengths`의 위치별 영역. 천간·십성 전체 요약은 지지 세력값으로 옮기지 않는다. |
| `guest_host_links`의 지지 관계 | `pairwise[].relations[]`의 `relation_id`, 작용 방향, 양쪽 역할에 연결한다. 기존 메커니즘 문구는 계산 근거와 구별한다. |
| `group_connections`의 참여 위치 | `groups[].formation_evidence[]`의 위치별 영역·구성 쌍에 연결한다. `cohesion_score`는 이전하지 않는다. |
| `pairwise_scores`, `group_cohesion_score`, `control_flow`의 단일 벡터 | 그대로 이전하지 않는다. 서로 다른 관계의 점수를 합산해 전체 주도권으로 판정하지 않는다. |
| 천간 관계, 직업 조언, AI 프롬프트 문구 | 지지 작용 결과에 혼합하지 않는다. 필요하면 별도 천간 분석·표현 계층에서 다룬다. |

`bin_zhu_dynamics`는 기존 응답과 테스트의 호환성을 위해 당분간 유지하되 새 지지 계산의 입력으로 사용하지 않는다. 새 출력의 필드와 사용처가 준비된 후 단계적으로 사용을 중단하고, 응답에서 제거하는 것은 API 버전 변경 시 결정한다. 이는 목표 구조이며 현재 API 응답이 이미 바뀌었다는 뜻은 아니다.
