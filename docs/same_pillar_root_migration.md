# 통근·허투 동주 기준 전환

> 2026-11-04 현행 변경: 동주 허실 v4는 관련 관계 기록과 통근 영향 판정을 분리합니다. 활성 관계만으로 점수를 제외하거나 변허로 전환하지 않습니다. 아래 v3의 관계 반영·변허 사례는 이전 동작 기록입니다. [현행 계약](root_relation_separation.md)을 참고하세요.

적용일: 2026-11-04. 사용자 결정에 따라 **천간의 통근과 허투는 같은 기둥의 지지에서만 판단**한다. 다른 세 지지의 기존 지원 경로는 `external_support`로 분리해 보존한다. [통근 계산기](../services/analysis.py)의 기본 범위가 `same_pillar_only`이고, [허실 계산기](../services/xu_shi.py)의 현행 원국 응답은 `rule_version: 3.0.0`, `root_scope: same_pillar_only`를 출력한다. 기존 전주 합산은 회귀 비교를 위해서만 명시적 `all_four_branches_weighted` 옵션과 v1 규칙 버전으로 남긴다.

## 판정·출력 의미

| 항목 | 동주 기준의 처리 |
| --- | --- |
| 동주 통근 여부 | 같은 기둥 천간·지지의 `ROOT_STRENGTH` 계수가 `0`보다 크면 참. 위치·거리 가중치를 사용하지 않음. `analysis.details[기둥].stem.same_pillar_root_exists`와 관계 조회의 `stem_state.has_same_pillar_root`에 표시 |
| 통근 점수 | 같은 기둥의 기존 `ROOT_STRENGTH` 계수 자체. 동주 점수에는 위치·거리 가중치를 적용하지 않음. 계수는 잠정값이며 크기는 실·허를 나누지 않고 뿌리 강도 정보로 남김 |
| 허투 | 동주 통근 여부가 거짓이고 점수가 `0`이면 허투. 다른 지지에서 지원 근거가 발견돼도 이를 허투 판정에 더하지 않음 |
| 허·실 | 동주 통근 점수가 `0`보다 크면 실. `0`은 기존 명칭 `허투`를 유지하며 허에 해당하는 상태로 본다. 관계 반영 후 동주 뿌리의 계산상 기여도가 완전히 사라지면 `변허`로 표시. 충·천·형이 닿은 뿌리의 전부 제외 가정은 잠정 규칙 |
| 타주 지원 | 이전 위치·거리 계수로 계산한 값과 지지별 근거를 `analysis.details[기둥].stem.external_support_*` 및 [관계 조회](../services/character_relation_index.py)의 `stem_state.external_support_*`에 별도 기록. 실·허투의 점수와 오행 집계에 더하지 않음 |
| 투출 | 상세 지장간과 천간 글자의 **정확한 일치**를 위치별 관계로 기록. 동주 통근 여부나 타주 지원의 대체 지표가 아님 |

`root_scope: same_pillar_only`는 **어디의 지지를 통근으로 세는지**를 뜻한다. 동주에서 정확히 같은 지장간 글자가 있어야만 통근한다는 뜻은 아니다. 기존 [통근 계수표 검토](root_strength_rule_review.md)처럼 같은 오행의 다른 지장간 글자를 인정한 조합도 현재 계수표에 남아 있다. 이 조합의 근거와 크기는 후속 검증 대상이다.

## 실제 달력 원국의 변경 대조

천간/지지는 연·월·일·시 순서다. 점수는 **관계 반영 전 통근 점수**이며 `→` 오른쪽이 동주 기준이다. 왼쪽 기록은 전주 가중 v1을 읽기 전용 달력 DB에서 실행한 값이고, 오른쪽은 동주 무가중 v3의 값이다. 아래 세 원국에는 점수 `0` 초과·`0.5` 미만인 동주 천간이 없어 v2.1→v3 상태 변화는 드러나지 않는다.

| 양력 일자·원국 | 연간 | 월간 | 일간 | 시간 |
| --- | --- | --- | --- | --- |
| 1990-01-01 `己丙丙甲 / 巳子寅午` | `0.80 실→변허` → `0.70 실→변허` | `1.11 실→변허` → `0 허투`(타주 지원 `1.11`) | `1.50 실→변허` → `0.60 실→변허` | `0.75 실→변허` → `0 허투`(타주 지원 `0.75`) |
| 1995-05-12 `乙辛癸己 / 亥巳卯未` | `0.37 허` → `0 허투`(타주 지원 `0.37`) | `0 허투` → `0 허투` | `0.12 허` → `0 허투`(타주 지원 `0.12`) | `1.28 실` → `1.00 실` |
| 2000-01-01 `己丙戊丙 / 卯子午辰` | `0.33 허` → `0 허투`(타주 지원 `0.33`) | `0.60 실→변허` → `0 허투`(타주 지원 `0.60`) | `1.15 실→변허` → `0.70 실→변허` | `0.60 실→변허` → `0 허투`(타주 지원 `0.60`) |

기존 `GET /`의 `analysis.details[*].stem.score/status/root_info`, `analysis.summary.total_energy_balance`, `advanced_analysis.xu_shi_dynamics`와, 그 통근 점수를 입력으로 쓰는 `advanced_analysis.five_elements.scores`가 달라질 수 있다. `GET /relation-index`의 `stem_state`에도 동주 통근 여부가 추가되며 조회 스키마는 `1.6-draft`다. 특히 `己丑`의 동주 점수 `0.2`는 v2.1에서 허였지만 v3에서 실이며, 활성 관계로 그 뿌리의 계산상 기여도가 0이 되면 변허다. 지지별 `branch_dynamics` 세력 산식과 관계 후보 판정은 이번 전환에서 바꾸지 않았다.

`analysis.summary.total_energy_balance`는 과거의 `실` 천간 개수 기반 신강·중화·신약 단정을 중단하고, 동주 통근/무근 개수와 `원국 전체 신강·신약 미판정`을 표시한다. 약한 통근도 실이므로 네 천간의 허실 개수를 전체 세력 판정으로 승격하지 않는다.

## 검증 경계

- [허실 테스트](../tests/test_xu_shi.py)는 동주 뿌리가 없지만 타주 지원이 있는 천간의 허투, 동주 뿌리가 충격을 받고 타주 지원이 남아도 변허인 사례, 명시적 전주 v1 회귀 자료를 따로 확인한다.
- [원국 통합 테스트](../tests/test_xu_shi_integration.py)는 새 규칙 버전과 네 천간의 `root_evidence`가 각각 **자기 기둥 지지**만 가리키는지 확인한다. [관계 조회 통합 테스트](../tests/test_character_relation_index_integration.py)는 타주 지원 점수가 기존 원국 응답과 일치하는지 확인한다.
- 현행 동주 판정에서는 `0.5` 실 경계를 사용하지 않는다. 활성 충·천·형의 **동주 뿌리 전체 제외**는 여전히 잠정 계량 규칙이다. 지지 위치·거리 가중치는 타주 지원과 명시적 전주 회귀 옵션에만 남아 있으며, 그 타주 지원 계수도 잠정값이다.

## 다음 작업

동주 통근의 **유무**와 뿌리 **강도**를 별도로 검토한다. 특히 [통근 계수표 검토](root_strength_rule_review.md)의 계수 미비·주석 불일치와, 동주 뿌리가 활성 구조의 영향을 받을 때 **전부 제외**하는 가정의 적절성을 사례로 확인한다. 타주 지원을 통근 점수에 다시 합산하지 않는다.
