# 자합 자료 대조와 사실 조회 계약

검토·반영일: 2026-11-13. 기존 구현은 `6b0cf25` / 규칙 `2.19.0` 기준으로 대조했다.
자합 사용자 결정 반영 시점의 규칙 버전은 `2.20.0`이다.
이후 육합·삼합 전체도 존재 정보로 정리했으며 현행 규칙은 `2.21.0`이다.
[합 조회 변경과 수치 영향](hap_presence_migration.md)을 함께 참조한다.

## 사용자 결정과 현재 동작

사용자는 자합 조합의 존재와 주변 未형·辰충의 존재를 정리하고,
자합이 성립하는지는 별도로 판단하도록 요청했다. 대화의 “술토”는
진토(辰)를 뜻한다고 확인했다.

- 기존 등록 조합 9개를 사실 조회 목록으로 유지한다.
- 未형이 있어도 자합을 자동 성립시키지 않는다.
- 辰충이 있어도 자합을 자동 불성립시키지 않는다.
- 자합은 모두 `detected`이고 실제 영향은 `not_evaluated`다.
- 다른 자합의 지지에 해당하는 충·형도 같은 원칙으로 주변 관계에 기록한다.
- 원국의 충·형 자체에 대한 기존 탐지·판정과 수치는 변경하지 않는다.

자합 목록과 학파별 해석 범위는 구분한다. 아래 자료의 차이를 없애기 위해
목록을 자동으로 축소하거나 범위를 확장하지 않았다.

未형은 프로젝트가 근거 없이 만든 조건은 아니다. 초급 자료의
“戌逢未刑开库时”와 “必须未刑，开库以后才可以合”에서 직접 확인했다.

다만 같은 항목만으로 모든 격위·거리·세력·중첩 상황을 단순 존재 여부로
자동 확정하는 구현까지 검증됐다고 보지는 않는다. 이번에는 사용자 결정에 따라
이런 해석을 사실 조회에서 분리했다.

중급의 6개 분류는 丁亥·戊子·己亥·辛巳·壬午·癸巳에 해당하는 내용이다.
목록의 `巳亥` 표기는 OCR 오류로 보이며 바로 다음 설명에서는 `己亥`를 사용한다.
이 차이를 교정 완료 원문이나 맹파 전체의 통일 정설로 단정하지 않는다.

## 현재 반환 구조와 설명

원자료: `analysis.details[기둥].jahab`.
글자 상세의 자합 근거: 중앙 `self_combine` 관계의 `evidence[*].details.records`.

자합 조합이 없으면 `null` 또는 중앙 관계 없음이다. 있으면 다음을 반환한다.

- `chars`, `my_index`, `exists=true`, `hidden_stem`, `candidate_element`
- `activation_status=detected`, `impact_status=not_evaluated`
- `related_branch_relations`: 해당 지지와 주변 지지의 충·형 사실 배열

주변 관계 항목은 `type`, `with`, `with_index`, `with_ten_star`, `distance`,
`is_adjacent`를 갖는다. `type`은 `clash`, `punishment`, `self_punishment`다.
관계가 없으면 빈 배열이며 같은 글자가 반복되면 위치별로 모두 남긴다.

이전 `active`, `is_conditional`, `condition_met`, `required_condition`,
`inactive_reason`, `blocking_chung`, `chung_impact`는 제거했다.
가장 강한 충 하나를 골라 영향처럼 표시하지 않는다.

중앙 관계는 기존 ID와 두 참여 글자를 유지한다. 주변 충·형의 중앙 ID는
근거의 `related_relation_ids`로 연결하고 관련 위치·십성도 함께 제공한다.
자합 본문은 조합 존재를, 주변 관계 설명은 함께 있는 충·형을 설명한다.
성립·불성립·개고 성공·손상량을 추론하지 않는다. 자합에 다른 상태 판정을
다시 넣으면 원국 조회 계약과 공통 그래프 검사가 거부한다.

## 검증 범위

이전 코드에서는 9개 자합에 대응 충을 넣었을 때 7개는 활성 유지,
丙戌·壬戌만 차단됨을 재현했다. 변경 후에는 9개 × 4개 자기 위치 × 3개 상대 위치,
총 108개 원국에서 조합·충 존재 보존과 자합 탐지 상태를 검사한다.
未·辰 없음/각각 있음/함께 있음/반복 辰, 자합 없는 조합,
성립 판정 재도입 거부와 원본 비변경도 회귀 검사한다.
자합 정리 단계의 전체 회귀 검사 255개가 통과했고 기본 `/`, `/character-details`,
`/cycle-analysis`의 실제 HTTP 전달을 확인했다. 변경 전후 18개 원국에서
규칙 버전 메타데이터를 제외한 원국·지지·통근 계산 결과가 동일했다.
이후 육합 자동 성립에 따른 억제 제거로 생긴 지지 배경 변화는 위 합 조회 변경 문서를 따른다.

현행 검토 결과는 이전 [조건부 검토](conditional_state_review.md)의
“미충족 자합을 후보로 바꾸는 방안”보다 우선한다. 이번 구현은 자합 전체를
사실 탐지로 정리한 사용자 결정이며 새 성립 규칙을 확정한 작업이 아니다.
