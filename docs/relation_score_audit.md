# 관계 점수 총계 검토

> **제거 전 검토 기록.** 사용자 결정으로 아래 점수·기후·빈주 판정을 제거했다.
> 현행 반환 계약은 [관계 점수 제거](relation_score_retirement.md)를 따른다.
> 이 문서와 `relation_score_audit_examples.json`의 값은 제거 전 증거이며 현재 API 예시가 아니다.

2026-11-13. 실행 규칙 `2.21.0`, 매트릭스 집계 버전 `1.3.0`, 빈주 `3.0.0`.
육합·삼합을 사실 조회로 통일한 뒤의 코드와 실제 결과를 점검했다.
이번 검토는 점수 계산 코드·계수·출력 계약을 변경하지 않았다.

## 결론과 우선순위

총계는 관계별 고정 가중치를 합산하는 잠정 지표다. 실제 세력·피해·합화 또는
원국의 안정성을 검증한 점수가 아니다. 그런데 결과에서 기후 유형과 우세 설명을
자동 생성하므로, 현재의 “관계 존재와 성립·영향을 분리”하는 정책과 맞지 않는 부분이 남아 있다.

**권장 방향은 점수 정밀화보다 총계 기반 유형·우세 판정의 축소·폐기다.**
관계 목록·위치·십성·구성 근거·관련 관계 ID는 유지한다.
수치 모델이나 손상률·계수 추정을 새로 시작하지 않는다.

## 1. 현재 계산 구조

주 계산은 [매트릭스](../services/interaction_matrix.py)다.
쌍 관계 거리 가중치는 위치 차이 1이면 1.0, 2이면 0.7, 3이면 0.5다.

| 항목 | 기본 점수 | 집계 |
| --- | --- | --- |
| 지지 충 | 2.0 × 거리 | 긴장 |
| 지지 천·지세형 | 1.5 × 거리 | 긴장 |
| 지지 파 | 1.0 × 거리 | 긴장 |
| 천간 충 | 1.5 × 거리 | 긴장 |
| 천간 합 | 1.8 × 거리 | 조화 |
| 육합 | 1.5 × 거리, 조합에 인접 충이 있으면 0 | 조화 |
| 전반합·후반합 | 각각 1.3·1.1 × 거리, 소수 둘째 자리 반올림 | 조화 |
| 삼합 | 3.0, 중신 중복 또는 구성 지지 인접 충이 있으면 0 | 조화 |
| 방합 | 3.5, 거리·조합 수에 따른 추가 가중 없음 | 조화 |
| 자형·삼형·공합·암합 | 0 | 관계는 보존하며 독립 점수 미가산 |
| 천간 극·자합·투간·일반 생극 | 이 매트릭스 총계에 포함하지 않음 | 별도 관계 경로 |

`score`는 개별 점수, `score_contribution`은 총계 기여다.
점수가 양수인 삼합·방합의 실제 세 자리 조합 안에 들어가는 육합·반합은
개별 관계와 점수를 유지하면서 기여만 0으로 한다. 포함 그룹은 `score_covered_by`로 연결한다.
삼합의 내부 반합은 원래 매트릭스에서 별도 쌍으로 출력하지 않는 경우도 있다.

- `tension_score`: 탐지 루프에서 긴장 점수를 누적하고 소수 첫째 자리 반올림.
- `harmony_score`: 중복 기여 조정 후 조화 유형의 기여를 합산하고 첫째 자리 반올림.
- `climate`: **반올림 전** 긴장과 조화의 차이가 2를 넘는지로 세 문구 중 하나를 선택.

분류 문구는 긴장 우세 시 `격렬한 변동과 도전형`, 조화 우세 시
`유화적이고 안정적인 조화형`, 나머지는 `긴장과 조화가 공존하는 복합형`이다.
이는 명리 자료에서 계량 검증된 분류가 아니라 현재 프로그램의 비교 규칙이다.

### 빈주의 별도 점수

[빈주 계산](../services/bin_zhu.py)은 년·월(빈)과 일·시(주)를 가로지르는 관계만 집계한다.
같은 빈 내부·주 내부 관계는 제외한다. 파·공합·암합도 쌍별 점수에서 제외한다.
대상 관계의 기존 `score`를 더하고, 점수 없는 입력에는 별도 기본값을 사용한다.
기본 API 매트릭스에는 점수가 항상 있으므로 해당 기본값은 현재 정상 경로의 주 계산이 아니다.

- `pairwise_scores.combination`, `conflict`: 빈–주를 잇는 해당 유형의 개별 점수 합.
- `unweighted_*`: 합은 건당 2.0, 충·형·천은 건당 1.5로 집계한 별도 값.
- `group_cohesion_score`: 그룹 기본값 3.0/3.5 × `(빈 위치 수 × 주 위치 수) / 전체 참여 위치 수`.
  중신 중복·충 등의 관찰이 있으면 기존 정책에 따라 0이다.
- 다자 점수는 쌍별 점수에 합산하지 않지만, 양수 여부가 `has_bridging_group`과 우세 설명에 사용된다.

빈주는 `score_contribution`을 사용하지 않는다. 예를 들어 `巳午未寅`의 午未 육합은
전체 조화 총계에서는 방합 중복으로 기여 0이지만, 빈–주 쌍별 점수에는 1.5로 들어간다.
집계 목적과 범위가 달라 전체 조화 점수와 빈주 합 점수를 바로 비교할 수 없다.

## 2. 확인한 문제

### 높은 우선순위: 잠정 점수를 다시 해석 판정으로 사용

육합·삼합 상태는 `detected`지만 `climate`가 안정·격렬 유형을 판단한다.
빈주도 그룹 점수가 양수이면 “다자 합이 형성”, 두 점수 비교로 “합 관계 우세” 같은
문구를 만든다. 조합 존재를 실제 성립이나 원국의 성격으로 다시 해석할 여지가 있다.

이 문구와 점수는 [원국 조립기](../services/saju_orchestrator.py)의
`advanced_analysis.ai_consultation_prompts`에도 복사된다. 프론트엔드만 숨겨도
API 소비자가 해당 문장을 이용할 수 있으므로 생산 지점에서 정리하는 것이 좋다.

### 계산 일관성: 합산·반올림 순서와 유형 비교 기준이 다름

지지 `12^4 = 20,736`개 배열을 천간 `甲甲甲甲`으로 고정해 전수 점검했다.
달력 생년월일이나 실제 인구 분포의 빈도를 뜻하지 않는다.

| 검사 | 확인 결과 |
| --- | ---: |
| 지지 배열 | 20,736건 |
| 긴장 총계를 Python 3.12의 `sum(매트릭스 항목)`으로 재구성했을 때 차이 | 6건 |
| 표시된 두 총점에 같은 유형 분류식을 적용했을 때 반환 문구와 차이 | 178건 |
| 긴장·조화 모두 0 | 1,342건 |
| 그중 매트릭스 관계 항목 자체가 없음 | 444건 |

예:

- `丑戌未丑`: 긴장 총계 7.5, 개별 항목을 다시 `sum`한 뒤 반올림하면 7.4.
  개별 항목에는 `1.0499999999999998` 같은 이진 부동소수점 표현이 포함된다.
  반복 덧셈과 합산 방식의 차이가 0.1로 노출된다. 어느 반올림 방식을 기준으로 할지도 명시돼 있지 않다.
- `子丑寅辰`: 긴장 0.0, 조화 2.0으로 반환하지만 반올림 전 조화 2.05를 사용해 조화형으로 분류한다.
  표시 점수로 같은 비교를 하면 차이가 2를 넘지 않아 복합형이 된다.
- `子子子子`: 매트릭스 관계 항목이 없고 두 점수가 모두 0인데도 “긴장과 조화가 공존”한다고 반환한다.

조화 총계의 기여 합산과 기존 그룹 중복 제외 참조는 전수 점검에서 정합했다.
긴장 총계 재구성 차이는 합산·반올림 문제이며 관계 탐지 누락으로 확인된 것은 아니다.

### 점수 0의 의미가 여러 가지

- 공합·암합·자형·삼형: 독립 수치를 매기지 않음.
- 육합·삼합의 특정 주변 구성: 기존 집계 정책에서 제외.
- 양수였던 육합·반합의 그룹 중복: 총계 기여만 제외.
- 관계가 없어서 합산 항목 자체가 없음.

이들이 같은 0으로 표현된다. `score_covered_by`가 세 번째 이유만 설명하며,
나머지는 일반적인 점수 상태·사유 필드가 없다. 0을 약함·없음·불성립으로 해석하면 잘못된다.

### 사실 조회와 어긋나는 기존 제외 정책

`亥卯未亥`와 `亥卯卯未`는 모두 삼합을 탐지하고 두 위치 조합을 제공하지만,
전자는 조화 3.0·조화형, 후자는 중신 중복을 이유로 조화 0·복합형이다.
중신 중복의 성립 판단을 분리했어도 총계를 통한 간접 판단은 남아 있는 셈이다.
이 제외 정책의 계량 근거를 새로 검증하거나 확정한 것은 아니다.

### 유지보수와 범위 표시

긴장은 탐지 도중 누적하고 조화는 마지막에 재합산하는 두 경로다.
관계별 계수는 탐지 함수 안에 분산돼 있고, 반올림도 일관되지 않다.
빈주와 전체 매트릭스의 대상·중복 처리도 다르므로 같은 종류의 총점처럼 노출하면 혼동된다.
`interactions`에는 내부 지지 모델과 달리 `score_meaning`이나 점수별 상태도 없다.
육합·삼합과 빈주 그룹은 `status_reasons`가 비어 있지 않으면 점수를 0으로 두므로,
향후 순수한 관찰 코드를 추가해도 집계 결과가 바뀔 수 있다. 사실 근거의 추가와
점수 제외 정책이 같은 목록에 연결돼 있는 점도 정리 대상이다.

## 3. 개선 권장 순서 — 이번에는 미구현

1. **총계 기반 해석 문구부터 정리한다.** `climate`, 빈주의 우세·다자 합 형성 문구,
   이를 복사한 프롬프트를 우선 축소·제거한다. 관계와 근거는 보존한다.
2. **총계 필드의 필요성을 결정한다.** 현재 목적이 관계 사실을 프론트엔드에 전달하는
   것이라면 긴장·조화 총계와 빈주 우세 점수를 폐기하는 편이 단순하다.
   점수 부여·보정·검증 체계를 새로 늘릴 필요는 없다.
3. **남길 점수가 있다면 최소한의 계약만 명시한다.** 집계 범위·잠정 의미·0의 이유,
   일관된 소수 정밀도·합산 경로를 정한다. 반올림 전후 어느 값을 표시·분류에 사용할지도 통일한다.
4. **개별 점수는 내부 의존을 확인한 뒤 정리한다.** 빈주가 `score`를 읽고,
   지지 그룹의 중첩 근거가 `score_covered_by`를 읽는다. 개별 필드를 일괄 삭제하지 않고
   존재·참여 조합 자료로 필요한 근거를 유지할 수 있는지 확인한다.

새 API·별도 점수 서비스·LLM 해석·계수 조정은 제안 범위에 포함하지 않는다.
일반 오행 분포의 점수와 통근 점수는 이 관계 총계와 별도이므로 함께 삭제하는 대상으로 보지 않는다.

## 검증 기록

- 현행 매트릭스 테스트 16개, 빈주 테스트 10개 통과.
- 위 전수 점검은 별도 합성 입력 검사이며 기존 테스트의 경계 누락을 드러냈다.
- [검토 집계와 재현 사례](relation_score_audit_examples.json)에 범위·건수·대표 입력과 출력을 남겼다.
- 이번 변경은 검토 문서·사례만 추가하며 계산 로직·계수는 그대로다.
