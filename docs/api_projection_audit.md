# 루트 기반 조회 API 정합성 점검

2026-11-13. 고 분류·요약 정리까지 보강한 루트 결과를 기준으로 다른 조회 API를 점검했다.
정상 결과의 전달은 일치했으며, 잘못된 응답 자료를 허용하던 계약 검증을 보강했다.

## API별 범위와 결과

| API | 루트에서 재사용하는 자료 | 점검 결과 |
| --- | --- | --- |
| `/relation-index` | 원국 여덟 글자, 중앙 관계, 동주 통근·타주 지원과 출처 | 관계 ID·상태·참조·통근 값 일치 |
| `/character-details` | 글자 속성·기둥 속성·원자료 분석·관계 근거와 설명 | 고 분류와 기존 십성·관계·통근 자료 보존 |
| `/cycle-analysis` | 위 원국 자료와 루트 대운·세운 목록에서 선택한 글자·기간 | 원국 자료 보존, 운 선택과 기간 경계 일치 |

`/relation-index`는 관계·통근 조회용 최소 계약이다. 고의 역할은 관계가 아닌 글자 분석 속성이므로
이 경로에 별도 고 필드를 중복 추가하지 않았다. 고는 루트 또는 상세 조회의 원국 지지 분석에서 읽는다.

`analysis.summary`, 오행 분포, 신살의 전체 근거 목록 등 루트의 전체 원국 자료를
모든 조회 API에 복제하지 않는다. 상세 조회에는 기존 기둥별 신살 이름이 전달되고,
신살 전체 탐지 근거는 루트의 `advanced_analysis.special_stars`에서 조회한다.

기본 그래프 버전 `1.0-draft`, 관계 인덱스 `1.7-draft`와 탐지 규칙은 유지한다.
새 API·관계 종류·고의 크기·개고·운 통근 판정을 추가하지 않았다.

## 확인한 검증 허점과 수정

다음은 정상 생성 결과의 오출력이 아니라 **구성한 잘못된 응답 자료가 모델 검증을 통과하던 문제**다.

### 원국 글자 분석 타입과 고 분류

`CharacterDetail.analysis`가 임의 사전이어서 루트의 상세 타입을 활용하지 못했다.
원국 천간·원국 지지·운의 후보 상태를 구체적인 세 타입으로 정의하고 OpenAPI에도 공개했다.
소속과 글자 종류에 맞는 분석만 허용하며 원국 글자·통근 요약의 수치를 상호 확인한다.

- `storehouse` 누락, 미등록 역할·오행, 개고 같은 미구현 필드의 삽입을 거부한다.
- 허용된 역할 이름이라도 해당 지지의 기존 지장간 십성과 다르면 거부한다.
- 원국 여덟 글자·계산 완료 소속·천간 통근 자료의 누락과 분석/통근 값 불일치를 거부한다.
- 운 분석은 후보 탐지 상태·통근 미평가만 제공한다. 원국 분석이나 통근 판정을 복사한 자료를 거부한다.
- 아직 탐지하지 않은 합성 확장 소속에는 `not_evaluated` 상태를 사용할 수 있다.
  실제 `/cycle-analysis`의 선택 운은 `candidates_detected`여야 한다.

### 관계 인덱스의 통근 미평가 정책

기존 관계 인덱스 모델은 미평가 상태인데도 `변허`·잔여 점수 감소를 수용할 수 있었다.
현행 루트와 상세 조회의 동주 정책에 맞게 검증을 통일했다.

- 상태는 `실(實)` 또는 `허투(虛透)`다.
- 원상태와 현재 상태, 원점수와 잔여 점수는 같아야 한다.
- 영향받은 뿌리 목록은 비어 있어야 한다.
- 동주 뿌리는 해당 천간의 같은 위치 지지이며 타주 지원에 자기 지지가 섞이면 안 된다.

### 운 선택 메타데이터

선택 ID와 소속 ID는 일치해도 소속 내부의 대운 번호·세운 연도가 다를 수 있었다.
선택 대운 번호, 실제 반열린 연도 범위, 기간 기준을 확인하고, 선택 세운이 그 범위에
포함되는지 검증한다. 세운의 연도·달력 연도 기준·세는나이 기준도 소속 메타데이터와 대조한다.
운 소속의 후보 탐지 상태도 최상위 선택 정보와 일치해야 한다.

## 검증

- 출생 입력 6건 × 루트·관계·글자·운 선택의 **42회 HTTP 조회** 성공.
- 양력, 음력 평달·윤달, 윤년 2월 29일, 반복 삼합, 남·여 입력 포함.
- 첫·마지막 대운, 출생 연도의 첫 대운 이전 세운, 대운 경계 연도 조회를 포함했다.
- 원국의 상세 분석·고 분류·속성·기둥 정보·통근·관계 ID와 설명이 각 API에서 보존됨을 확인했다.
- 변경 전후 42개 응답 본문의 JSON 키·값이 동일했다. 검증 보강으로 새 결과를 만들지 않았다.
- 잘못된 고 분류·통근 소멸·원국 통근 누락·대운 메타데이터 불일치 네 사례가
  변경 전에는 허용됐고 이후에는 모두 거부됐다.
- 원국 소속/여덟 글자 누락, 분석 종류·통근 값 불일치, 대운 범위·세운 기준·운 상태 변조도 검사했다.
- 전체 `.venv312/bin/python -m unittest discover -s tests`: **304개 통과**.

[입력별 점검 요약](api_projection_audit_examples.json)에 입력·글자/관계 수·고 분류·선택 조건을 보존했다.
주요 회귀 검사는 `tests/test_api_projection_audit.py`다.
기존 인덱스·루트 요약·고 분류 변경을 포함해 현재 추가 작업은 아직 커밋·푸시·환경 게시하지 않았다.
