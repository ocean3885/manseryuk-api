# 통근 계수와 지장간 투출의 불일치 19쌍 검토

> 2026-11-04 현행 변경: 동주 허실 v4는 관련 관계 기록과 통근 영향 판정을 분리합니다. 활성 관계만으로 점수를 제외하거나 변허로 전환하지 않습니다. 아래 v3의 관계 반영·변허 사례는 이전 동작 기록입니다. [현행 계약](root_relation_separation.md)을 참고하세요.

검토일: 2026-11-03. [120조합 교차 감사](transmission_rooting_alignment_audit.md)의 **투출만 3쌍·통근만 16쌍**을 현행 규칙표·상세 지장간·공개 원문 자료로 다시 분류한다. 아래의 분류는 **코드가 무엇을 표현하는지**를 설명하며, 계수의 임상 정확도나 맹파명리 최종 판정을 승인하지 않는다.

**2026-11-04 후속 결정:** [동주 기준 전환](same_pillar_root_migration.md)으로 원국 응답의 통근·허투는 동주 지지에서만 판정한다. 아래 `all_four_branches_weighted` 설명은 **전환 전 v1 비교 기록**이다. 19쌍의 `ROOT_STRENGTH` 계수 자체와 지장간 대조 표는 그대로이며, 다른 지지의 양의 계수는 `external_support`의 출처로 따로 보존한다.

**2026-11-04 동주 허실 v3:** 현행 동주 허실은 양의 계수를 모두 실로, 0을 허투로 분류한다. 아래 `0.5` 기준 언급은 전주 v1 당시의 기록이며 현행 실 경계가 아니다. 계수의 강도와 통근 인정 조합은 여전히 검토 대상이다.

## 먼저 구분할 규칙 범위

[전환 전 통근 계산](../services/analysis.py)의 `all_four_branches_weighted` 프로필은 한 천간에서 **네 지지 모두**를 훑고 `ROOT_STRENGTH × 지지 위치 가중치 × 거리 감쇠`를 합산했다. 반면 [段建業 명의 《盲派速成教程》의 통근 절](https://www.scribd.com/document/805625450/%E6%AE%B5%E5%BB%BA%E4%B8%9A%E6%9C%80%E6%96%B0%E7%9B%B2%E6%B4%BE%E9%80%9F%E6%88%90%E6%95%99%E7%A8%8B-111%E9%A1%B5)은 통근을 **동주 간지의 근**으로 제한한다고 설명한다. 그 절은 甲辰·丁巳 등 정확히 같은 지장간 글자가 없어도 근으로 보는 예를 든다. 같은 글자 일치만을 통근의 필요조건으로 삼는 것도 해당 설명과 맞지 않는다.

다른 전통인 [《子平真詮》의 「論十干得時不旺失時不弱」 원문과 번역](https://libokang.com/zh-hant/classics/bazi/%E5%AD%90%E5%B9%B3%E7%9C%9F%E8%A9%AE%E5%8E%9F%E6%96%87/)은 네 기둥의 근과 동오행 지장간의 묘고·여기 등을 함께 논한다. 이는 **학파·분석 범위가 다를 수 있다는 비교 근거**이며, 프로젝트의 현재 계수표 `0.2~1.0`이나 `0.5` 실 기준을 검증하는 자료는 아니다. 현 코드를 곧바로 段建業의 동주 통근 규칙과 동일시하지 않는다.

이 범위 차이를 사용자가 확인할 수 있도록 [관계 조회의 천간 상태](../schemas/character_relation_index.py)에 `root_scope: all_four_branches_weighted`를 추가하고 버전을 `1.3-draft`로 올렸다. 기존 점수·상태·지지 세력 계산식은 바꾸지 않았다.

## 통근만 인정한 16쌍의 공통 구조

16쌍 **모두** 상세 지장간 안에 해당 천간과 **오행이 같은 다른 천간**이 있다. 이번 전수 검사에서 `ROOT_STRENGTH > 0`인데 같은 오행 지장간조차 없는 경우는 **0건**이었다. `동오행 지장간 존재`는 코드 구조의 공통점이다. 실제 유효한 근인지와 계수의 크기는 별도 검토다.

| 천간–지지 | 통근 계수 | 같은 오행 지장간(상세표의 자리·비율) | 코드 수준 분류 |
| --- | ---: | --- | --- |
| 甲辰 | 0.3 | 乙 초기 `9/30` | 동오행 글자에 근거한 간접 통근 후보 |
| 甲未 | 0.2 | 乙 중기 `3/30` | 동일 |
| 乙寅 | 0.4 | 甲 정기 `16/30` | 동일 |
| 丁巳 | 0.7 | 丙 정기 `16/30` | 동일 |
| 戊丑 | 0.2 | 己 정기 `18/30` | 동일 |
| 戊午 | 0.7 | 己 중기 `9/30` | 동일 |
| 戊未 | 1.0 | 己 정기 `18/30` | 동일; 규칙 주석 재검토 필요 |
| 己辰 | 0.3 | 戊 정기 `18/30` | 동일 |
| 己巳 | 0.7 | 戊 초기 `7/30` | 동일 |
| 己戌 | 0.7 | 戊 정기 `18/30` | 동일 |
| 庚丑 | 0.5 | 辛 중기 `3/30` | 동일; 규칙 주석 재검토 필요 |
| 庚戌 | 0.3 | 辛 초기 `9/30` | 동일 |
| 辛申 | 0.5 | 庚 정기 `16/30` | 동일; 규칙 주석 재검토 필요 |
| 壬丑 | 0.3 | 癸 초기 `9/30` | 동일 |
| 壬辰 | 0.5 | 癸 중기 `3/30` | 동일 |
| 癸亥 | 0.6 | 壬 정기 `16/30` | 동일; 규칙 주석 재검토 필요 |

양의 통근 계수가 있다고 해서 **동오행 지장간마다 일정한 배율을 적용한 표**인 것은 아니다. 같은 `3/30` 중기 乙의 甲未 계수는 `0.2`이고, 같은 `3/30` 중기 辛의 庚丑 계수는 `0.5`다. 이 값들을 지장간 비율 하나로 역산하지 않는다. 현재는 `동오행 지장간이 있다`는 **탐지 가능한 출처**와 `얼마나 실로 인정할지`라는 **미검증 계량 결정**을 분리한다.

## 투출만 인정한 3쌍

| 천간–지지 | 정확히 같은 지장간 | 현재 통근 계수 | 결론 상태 |
| --- | --- | ---: | --- |
| 戊寅 | 戊 초기 `7/30` | 0 | **의도 미확인**. 정확한 투출 사실은 유지 |
| 戊申 | 戊 초기 `7/30` | 0 | **의도 미확인**. 정확한 투출 사실은 유지 |
| 戊亥 | 戊 초기 `7/30` | 0 | **의도 미확인**. 정확한 투출 사실은 유지 |

세 쌍의 같은 패턴만으로 `초기 戊는 통근에서 제외`라고 일반화할 수 없다. 같은 상세표에서 **戊巳도 戊 초기 `7/30`이지만 통근 계수는 `0.7`**이다. [원문 교재의 통근 설명](https://www.scribd.com/document/805625450/%E6%AE%B5%E5%BB%BA%E4%B8%9A%E6%9C%80%E6%96%B0%E7%9B%B2%E6%B4%BE%E9%80%9F%E6%88%90%E6%95%99%E7%A8%8B-111%E9%A1%B5)만으로 이 네 조합의 차이나 현재 수치를 확정할 수 없다. 현재의 戊亥 `투출 있음·통근 원점수 0`은 [경계 원국](transmission_rooting_alignment_audit.md)에서 재현했지만, 해석 결론은 보류한다.

## 규칙표 주석의 확인 필요 항목

다음은 **실행 계수**와 **그 옆 설명 문장**의 불일치다. 주석만 고치거나 숫자만 바꾸면 의도한 규칙을 놓칠 수 있으므로 현재 값은 유지했다.

| 위치 | 관측된 차이 | 판정 |
| --- | --- | --- |
| [戊未 통근 계수](../services/constants.py) | 계수 `1.0`의 주석은 未의 본기를 戊로 쓰지만, 상세 지장간의 未 정기는 己 | 주석의 근거 글자 재검토 필요. 계수 타당성 미확정 |
| [辛申 통근 계수](../services/constants.py) | 계수 `0.5`가 있으면서 주석은 辛이 申을 뿌리로 인정하지 않는다고 설명 | 숫자·문장 중 어느 쪽을 의도했는지 확인 필요 |
| [癸亥 통근 계수](../services/constants.py) | 계수 `0.6`이 있으면서 주석은 癸가 亥를 뿌리로 보지 않는다고 설명 | 동일 |
| [庚丑 통근 계수](../services/constants.py) | 庚丑 항목의 주석은 癸·壬水의 간접 힘을 설명해 庚의 금 통근 계수 근거와 바로 연결되지 않음 | 주석 또는 계수 출처 확인 필요 |

## 개발 판단과 남은 자료

1. [관계 조회 계약](character_relation_index_contract.md)의 `cross_layer:transmission`은 **정확한 지장간 글자 일치**만 기록하고, 현행 `stem_state`는 **동주 무가중 v3** 결과와 별도 타주 지원을 기록한다. 한쪽의 결과를 다른 쪽에 덮어쓰거나 독립 가산하지 않는다.
2. 16쌍에는 `same_element_hidden_stem`이라는 **검토 분류**를, 3쌍에는 `literal_hidden_stem_without_modeled_root`라는 **검토 분류**를 문서상 부여한다. 두 분류를 아직 생산 규칙의 확정 성립·손상량으로 사용하지 않는다.
3. 범위는 동주로 확정되었다. 남은 검토는 계수표의 인정 조합·강도 근거와 활성 충·천·형에서 뿌리를 전부 제외하는 가정이다. [120조합 재검토와 합성 반례](same_pillar_root_audit.md)에 재현 결과와 검토 순서를 기록했다.

근거가 확정되기 전에는 `ROOT_STRENGTH` 계수를 수정하지 않는다. `0.5` 임계값은 전주 v1 회귀에만 남고 현행 동주 v3에는 적용하지 않는다. [지지 세력](../services/branch_dynamics.py)에 통근 점수를 새로 반영하지도 않는다.
