# 루트 표시 자료·신살 기준·상세 응답 타입

2026-11-13. 루트 응답을 프론트엔드에서 사용할 때 남아 있던 세 항목을 정리했다.
신살 탐지 기준, 설명 문구, 상세 타입 순서로 적용했다. 새 API는 추가하지 않았다.

## 신살 탐지 기준

기존 조합표를 유지하며 아래 기준을 각각 검사한다. 다른 학파의 조합을 새로 추가하지 않았다.
이 표는 현재 프로젝트의 등록 규칙이며 학파 전체의 유일한 기준이라는 뜻이 아니다.

| 신살 | 탐지 기준 | 이번 계산 변경 |
| --- | --- | --- |
| 천을귀인 | 일간·년간 각각 | 기존 검사 유지, 근거 추가 |
| 문창귀인 | 일간 | 기존 검사 유지, 근거 추가 |
| 도화·역마·화개 | 일지·년지 각각 | 년지 검사 복원 |
| 양인·홍염 | 일간 | 기존 검사 유지, 근거 추가 |
| 백호·괴강 | 각 대상 기둥의 간지 쌍 | 기존 검사 유지, 근거 추가 |

이전 `MAP.get(day_branch) or MAP.get(year_branch)`는 유효한 모든 일지에 값이 있어
년지를 검사하지 않았다. 일지·년지 양쪽을 독립 검사하도록 수정했다.
예를 들어 년지 申·일지 寅, 월지 卯·시지 酉이면 도화는 월지(일지 기준)와
시지(년지 기준) 양쪽에 반환한다. 기존 일지 기준 결과를 제거하지 않는다.

신살의 위치별 행은 `(name, pillar)` 기준으로 한 번만 반환한다.
기준 두 개가 같은 대상에 일치하면 행을 복제하지 않고 두 근거를 보존한다.
같은 글자가 여러 대상 위치에 반복되면 대상별 행을 유지한다.
자기 위치의 신살을 제외하는 새 규칙이나 신살의 강약·현실 발현 판정은 추가하지 않았다.

### 신살 응답

기존 `name`, `pillar`, `position`, `char`, `type`, `description`을 유지하고 다음을 추가한다.

| 필드 | 의미 |
| --- | --- |
| `rule_id` | 실제 적용한 등록 규칙 ID |
| `basis[]` | 일치한 기준 글자의 `pillar`, `kind`, `char`, `display_name` |
| `interpretation_scope` | `traditional_symbolism`: 설명은 전통적 상징 |

`kind`는 `stem`, `branch`, `pillar`다. 간지 쌍 기준의 `char`는 두 글자다.
`basis`는 비어 있지 않으며 일간/일지 기준 다음에 년간/년지 기준을 기록한다.
`description`은 “전통적 상징:”으로 시작하는 상징 설명으로 정리했다.
“능력 우수”, “학문적 성취”, “엄청난 총명함”, 사건·성과의 확정 문구는 제거했다.

결과는 `advanced_analysis.special_stars`, `special_stars_by_pillar`,
`four_pillars.<pillar>.special_stars`에 일관되게 반영한다.
원국표의 신살 이름 목록과 글자 조회의 기둥 속성에도 년지 검사 복원이 반영된다.

## 관계와 오행 표시 의미

매트릭스의 충·천·파·천간충 요약은 위치·글자·관계의 존재를 설명하도록 정리했다.
“기반 변동”, “손상”, “파괴”, “직접적인 대립” 같은 자동 결과 해석은 제거했다.
기존 인접 자형·삼형의 존재 규칙과 상태는 유지한다.
관계 ID·관찰 근거·성립 범위·실제 영향 미평가 정책도 유지한다.

오행의 두 목록은 개수 기준을 드러내도록 이름을 바꿨다.

| 이전 | 현재 | 기준 |
| --- | --- | --- |
| `dominant` | `frequent_elements` | 원국 여덟 글자의 대표 오행 중 3개 이상 |
| `deficient` | `absent_elements` | 대표 오행 0개 |

이전 필드의 별칭은 남기지 않는다. `counts`, `percentages`, `scores` 계산은 유지했다.
대표 오행의 개수·부재는 실제 세력 우세, 지장간 오행 부재, 보완 필요성의 판정이 아니다.
기존 `distribution_basis`·`score_meaning`으로 개수 통계와 잠정 가중 지표를 구분한다.

## 상세 응답 타입

`schemas/natal_analysis.py`에서 다음 구조를 구체화했다.

- `analysis.details`: `year`, `month`, `day`, `hour`의 네 기둥을 요구한다.
- 각 기둥의 천간 통근·타주 지원, 지지 지장간·투간·미투간, 등록 자합.
- 천간 합·충·양방향 극과 지지의 관계 종류별 배열.
- 관계별 실제 참여 위치·십성·조합·중신·주변 충·반합 동반 근거.
- 매트릭스의 육합·삼합·반합 관찰 근거와 빈주 영역의 글자 표시 구조.

원자료에는 `TypedDict`를 사용해 선택 키의 부재와 명시적 `null`을 구분한다.
타입 적용만으로 사용하지 않던 필드나 기본 `null`이 응답에 추가되지 않게 했다.
등록하지 않은 키는 조용히 버리지 않고 거부한다. 관계 종류에 맞지 않는 상태나
잘못된 위치·숫자 자료도 검증한다. 상세한 OpenAPI가 함께 제공된다.

실험 지지 모델의 자유 형식 내부 근거와 `/character-details`의 전체 일반화 타입을
일괄 교체하지 않았다. 기존 조립기는 같은 원자료를 사용한다.

## 검증과 반영 사항

- 전체 `.venv312/bin/python -m unittest discover -s tests`: **278개 통과**.
- 일지·년지 개별 일치, 양쪽 일치·동일 글자, 반복 대상 위치, 일간 전용과
  동주 간지 전용 기준을 고정 사례로 검증했다.
- 실제 달력 DB를 읽는 HTTP 응답에서 탐지 근거의 글자·위치, 신살 목록의 일관성,
  오행 필드 교체와 OpenAPI의 상세 타입을 확인했다.
- 쌍 관계와 삼합·방합·삼형 반복 조합, 중신·날개 충의 원자료/근거를 타입에 통과시켜
  정보가 누락되지 않는지 확인했다. 잘못된 자료·미등록 키의 거부도 검사했다.
- 변경 전후 12개 합성 원국에서 원자료, 동주 통근 점수·상태, 지지 배경·잠정량,
  매트릭스 관계 ID·상태·근거와 중앙 글자 조회 결과는 동일했다.
  매트릭스의 의도된 설명 변경은 비교에서 제외했다.
- 신살 비교에서는 기존 탐지를 모두 유지하고 12개 중 7개에서 년지 기준 항목이 추가됐다.

프론트엔드는 오행 목록의 두 필드명을 교체하고 신살 상세에 `basis`와 상징 설명을 사용할 수 있다.
[반환 예시](root_display_examples.json)는 합성 원국이며 실제 출생 날짜를 주장하지 않는다.
별도 프론트엔드의 렌더링 검증은 수행하지 않았다. 커밋·푸시·환경 게시는 하지 않았다.
