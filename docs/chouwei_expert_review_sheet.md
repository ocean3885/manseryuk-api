# 축미충 A~D 전문가 검토 양식

상태: [목표·검증표](./branch_dynamics_acceptance_matrix.md)의 교재 해석 참고 4건을 **근거 단위로 대조**하기 위한 초안. [축미충 사례 대조](./chouwei_clash_analysis.md)에 각 교재의 출처 링크와 현재 계산값이 있다. 교재 문장은 참고 해석이며 손실률·현실 결과의 계량 정답은 아니다.

## 기입 원칙

- 각 판단에는 `교재 명시 / 계산 관측 / 전문가 판단 / 미확정` 중 근거 구분을 붙인다. 교재가 언급하지 않은 손상량·귀속은 빈칸을 임의 수치로 채우지 않는다.
- `관계 active`는 충의 **성립**, `power_before`는 상대를 제외한 **잠정 비교값**이다. 둘 다 충제·개고·충괴의 최종 판정이 아니다.
- 우세 세력, 피해 지지, 피해 지장간, 발현 가능성, 십신, 빈주 귀속, 중심 작용은 각각 독립적으로 검토한다. 한 단계의 판단을 다음 단계의 근거 없이 복사하지 않는다.
- 결론 상태는 `재현 / 근거 있는 이견 / 보류` 중 하나다. `재현`이라도 출처 경로와 반례 검토가 없으면 일반 규칙으로 승격하지 않는다.

### 원국별 기입 칸

| 단계 | 기록할 질문 | 증거와 상태 |
| --- | --- | --- |
| 원국·출처 | 천간·지지 4주, 자료 링크/쪽, 해석 문장, 출처의 범위 |  |
| 1. 위치 | 丑·未의 실제 기둥, 인접·격위, 충 후보 ID, 동시 성립 관계 |  |
| 2. 세력 출처 | 월령·동주 천간·다른 지지·그룹 중 **어느 출처가 어느 대상에** 기여하는가? 각 출처는 이미 배경값에 포함됐는가? |  |
| 3. 피해 대상 | 丑의 己·癸·辛, 未의 己·丁·乙 중 실제 손상·결속·발현 **후보와 근거**는? 지지 전체의 세력과 지장간별 상태를 분리했는가? |  |
| 4. 해석 맥락 | 일간 기준 십신·묘고의 대상, 손상과 활용 가능성의 차이는? |  |
| 5. 귀속 | 빈위·주위의 직접 위치와 천간·합·투출 등을 통한 귀속 경로는? |  |
| 6. 중심 작용 | 충제·개고·충괴 또는 복수 후보/보류 중 무엇이며, 이 판단을 바꿀 반례는? |  |
| 모델 대조 | 현재 출력의 근거 ID·세력·미해결 단계, 일치/불일치 원인, 추가 사례 필요성 |  |

## 네 사례의 검토 시작점

| ID·원국 | 1. 위치와 현행 후보 | 2. 교재가 든 세력 경로 / 현재 남은 질문 | 3~4. 언급된 대상과 해석 | 5~6. 귀속·유형과 확인할 질문 |
| --- | --- | --- | --- | --- |
| **A** `乙己己庚 / 巳丑未午` | 월 丑–일 未 인접 충 `active`; 丑午천 `active`, 巳午未 방합 `potential`, 午未합 `conditional` | 교재는 巳午未의 화·조토 기세로 未→丑을 읽는다. 현행 `P丑=2.2390 > P未=1.7537`; 巳·午→未의 일반 生은 이미 반영됐다. **방합의 추가 기여 대상·중복 여부는 미확정** | 교재는 丑 속 癸·辛 제압을 서술. 己 일간 기준 癸 편재·辛 식신. 두 지장간의 손상 경로와 정도는 아직 코드로 검증되지 않음 | 월 丑은 빈위, 일 未는 주위라는 위치 사실과 결과 귀속 판단은 별개. **未→丑 충제**가 어느 구조 근거에서 성립하는지, 癸·辛 모두 손상되는 조건은 무엇인지 검토 |
| **B** `丁癸丙壬 / 未丑子辰` | 연 未–월 丑 인접 충 `active` | 교재는 습토·수의 기세로 丑→未을 읽는다. 현행 `P丑=2.1133 > P未=1.2478`; 어떤 지지·지장간이 丑을 지원하는지 출처별 검토 필요 | 교재는 未 속 丁의 제압을 언급. 丙 일간 기준 丁 겁재. 다른 未 지장간의 손상 여부는 미확정 | 충 위치는 빈위–빈위. 교재는 천간·반합 등을 통한 주위 연결을 설명. **丑→未 충제**와 결과 귀속 경로를 따로 확인 |
| **C** `丁己辛辛 / 未酉丑卯` | 연 未–일 丑 격위 충 `active` | 현행 `P丑=1.3359 > P未=0.9622`. 격위 자체는 손실·개고의 충분 조건이 아님 | 교재는 원국의 격위 충을 개고로 설명. **어떤 지장간의 발현·활용이 가능한지**와 손상 여부를 분리해야 함 | 연 未 빈위–일 丑 주위. 원국의 개고와 뒤따르는 운의 직접 충·제압은 다른 사건. 개고가 누구에게 귀속되고 활용되는지 확인 |
| **D** `庚己丙乙 / 申丑申未` | 월 丑–시 未 격위 충 `active`; 申이 연·일에 반복 | 교재는 두 申과 丑의 연결로 丑→未을 읽는다. 현행 `P丑=2.0067 > P未=0.9472`; 반복 申의 入墓·지원 경로는 현재 그룹 결과만으로 표현되지 않음 | 교재는 未의 인성 창고와 乙의 제압을 언급. 丙 일간 기준 乙 정인. 乙의 손상과 창고 활용 가능성을 별도 확인 | 월 丑 빈위–시 未 주위. **丑→未 충제**의 세력 경로와 결과 귀속을 검토. 반복 申을 단순히 두 배 가산하지 않음 |

위 표의 교재 해석은 [사례 대조 문서](./chouwei_clash_analysis.md)의 요약이며, 전문가가 그대로 승인했다는 뜻이 아니다. 특히 A의 반대 방향 문제를 해결하려고 방합에 임의 배율을 추가하거나, C에서 격위라는 이유만으로 모든 창고를 연다고 판정해서는 안 된다.

A와 D의 계산 관측·출처별 비교·지장간 미해결 항목은 [A·D 세력 출처 추적](./chouwei_a_d_source_paths.md)에 별도로 기록했다. 그 문서의 일반 보정률은 교재가 말한 구조 작용의 수치가 아니다.

## A·D 계상 검토 결과와 남은 판단

[유지·대체·별도 작용 검토](./chouwei_a_d_accounting_review.md)에 두 사례의 주요 대상 네 곳에 대한 일반 배경 12경로와 구조·피해 후보를 대조했다. 다음은 전문가 승인과 구분한 개발상 결론이다.

| 항목 | 현재 처리 | 전문가 검토가 필요한 내용 |
| --- | --- | --- |
| A 巳·午→未의 일반 生 | 현재 수치 유지. 방합 경로는 겹침만 기록하고 미계산 | 방합이 일반 生을 대체하는지, 다른 대상·가용성에 작용하는지 |
| A 午→丑 일반 生 | 기존 丑午천에 따른 0 억제 유지 | 천의 피해 대상과 丑未충 피해의 중복 |
| D 두 申→丑의 일반 설기 | 위치별 음수 보정 유지. 入墓 설명만으로 삭제·양수 전환하지 않음 | 입묘의 실제 대상, 구조망과 일반 설기의 계상 관계 |
| A 癸·辛 / D 乙 피해 | 별도 지장간 대상으로 검토할 후보. 실제 계상 결정은 미정 | 주도 조건·손상 기전·발현 가능성 및 구조 의존의 범위 |
| 丑未 상호 동기 보정 | 전체 배경에는 유지, 충의 비교값에서는 상대 제외 | 충 후 최종 계상에서 유지/대체/손상과 어떻게 조정할지 |

현재 A·D에서 수치에 적용할 `replace`·`separate_effect`를 확정하지 않았다. 의미상 다른 후보라는 판단과 실제 독립 계상 결정을 구분한다. 다음 단계는 이 표의 사례 근거·대상을 외부 검토 후보 자료로 보존하는 작업이다.

## 검토자가 남길 결론

각 사례에 대해 다음 항목을 문장과 근거 ID로 남긴다.

1. 교재의 방향·대상·유형 해석에 대한 `동의 / 조건부 동의 / 이견 / 자료 부족`과 그 이유.
2. 세력 출처별 `기존 배경에 포함 / 구조 효과로 대체 / 독립 효과 / 미정` 및 대상 지지·지장간.
3. 손상·발현·귀속 각각의 확정 수준과 추가로 필요한 반례 원국.
4. 현재 모델의 불일치를 **기준 세력, 관계 경합, 지장간 상태, 귀속 경로** 중 어디서 설명해야 하는지.

이 검토가 끝나기 전에는 A~D의 교재 결론을 조합별 고정 규칙이나 손실 계수의 자동 회귀 기대값으로 승격하지 않는다.
