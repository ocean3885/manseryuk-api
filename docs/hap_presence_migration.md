# 육합·삼합 존재 정보 통일

> **후속 변경:** 아래 존재 조회 정책은 유지한다. 이행 당시 보존했던 관계 점수와
> 빈주 결속도는 이후 제거했다. 수치·점수 필드는 [현행 제거 계약](relation_score_retirement.md)을
> 우선한다. 이 문서의 점수 보존·0점 비교는 `2.21.0` 단계의 기록이다.

2026-11-13, 실행 규칙 `2.21.0`.
사용자는 중신 중복·외부 충만 정리하는 범위에서 확대해,
**육합·삼합 전체를 자합처럼 존재 정보로 통일**하도록 선택했다.

## 현재 계약

- 육합 여섯 조합과 삼합 네 조합을 위치별로 탐지한다.
- 충이 없거나 있거나, 충이 조합 사이·바깥 어디에 있거나, 중신이 중복돼도
  `activation_status=detected`다.
- 합화 여부·성립·불성립·합충 우선순위·실제 영향은 이 조회에서 결정하지 않는다.
- `status_reasons`에는 중신 중복·인접 충 등 **관찰 코드**를 보존한다.
  이것이 조건부·억제 판정의 사유라는 의미는 아니다.
- 기존 `condition_evidence`의 요약·충 위치·글자·십성을 유지한다.
  삼합은 `middle_count`, `middle_indices`, `middle_members`와 실제
  `formation_indices`를 제공한다. 같은 글자도 위치별로 구분한다.
- 육합에는 성립 규칙 ID를 붙이지 않는다(`activation_rule_id=null`).
- 중앙 관계 ID와 참여 글자·조합·후보 오행은 유지한다.

기본 `/` 원자료 → 매트릭스 → 내부 지지 모델 → `/relation-index` →
`/character-details` 및 `/cycle-analysis`의 원국 자료가 같은 상태를 사용한다.
원국 육합·삼합에 성립·차단 판정을 다시 넣으면 조회 계약이 거부한다.
운의 관계 탐지는 기존 소속 간 후보 계약을 유지한다.

## 설명

`presentation.status_label`은 `탐지`다. 중신 중복과 인접 충은
`reasons[*].category=structure`로 설명한다. `scope`에서 실제 성립과 작용을
확정하지 않았음을 안내한다. “조건부로 둡니다”, “성립을 억제합니다”는 제거했다.
`condition_evidence.summary`에도 판정 상태를 반복해서 붙이지 않는다.

예:

- `亥卯卯未`: 삼합 구성과 월·일 중신 卯 두 위치, 두 세 자리 조합을 보존한다.
- `午子丑寅`: 子丑 육합과 조합 바깥 午子충을 함께 기록한다.
- `子午丑寅`: 子丑 육합과 두 글자 사이 午子충을 함께 기록한다.
- `巳亥卯未`: 亥卯未 삼합과 생지 亥의 巳亥충, 다른 날개·중신의 卯未 반합 후보를 보존한다.

날개 충이 있다는 이유로 삼합의 존재를 지우거나 억제 상태로 바꾸지 않는다.
관련 반합 후보와 충 참조도 빠뜨리지 않는다.

## 점수와 내부 잠정 계산

관계 점수와 성립 상태를 분리했다. 기존 집계 정책과 계수는 유지한다.

| 자료 | 잠정 집계 정책 |
| --- | --- |
| 육합 점수 | 조합의 인접 충이 없으면 `1.5 × 거리 가중치`, 있으면 0 |
| 삼합 점수 | 중신 중복·구성 지지 인접 충이 없으면 3.0, 있으면 0 |
| 빈주 그룹 결속 점수 | 기존 중복·충 구성의 제외 정책 유지 |
| 충 개입 육합의 기존 v2 `force` | 기존 표시 정책의 0 유지. 실제 적용량이 아님 |
| 내부 v3 육합의 실제 적용량 | 항상 미확정 `null`. 예전 사이 충의 확정 차단·적용량 0도 제거 |
| 그룹 방향 | 실제 방향은 `undetermined`, 구조상 방향 후보는 후보로만 유지 |

따라서 점수 0을 보고 불성립·무영향·피해 없음으로 표시하지 않는다.
숫자가 양수여도 합화나 실제 발현을 확정하지 않는다.
수치 모델·계수 추정·최종 세력 연구를 재개한 것은 아니다.

### 자동 생·극 억제 제거에 따른 변화

이전에는 인접 충이 없는 육합을 자동 `active`로 판정하고 같은 위치 쌍의
생·극과 주변 보정을 억제했다. 이제 육합은 존재 사실만 확인하므로 이 자동
억제 경로가 발동하지 않는다. 생·극은 독립적인 오행 경로 후보로 남는다.
별도로 성립한 충·천·파·형의 기존 억제 규칙은 유지한다.

그 결과 일부 지지의 잠정 배경 세력·관계 잠재량은 달라진다.
변경 전후 13개 합성 원국에서 원국 글자·십성·천간 통근 자료·관계 ID 집합과
매트릭스의 개별 점수·총점은 동일했다. 지지 배경 결과가 달라진 것은 아래 6건이다.

`子丑寅辰`, `午子丑寅`, `子午丑寅`, `申寅亥子`, `戌未辰卯`, `巳午未寅`.

이는 합 존재를 성립으로 간주하던 연결을 제거한 결과다. 원국 전체 수치가
이전과 모두 같다고 안내하지 않는다.

## 검증

- 삼합 네 종류 × 중복 글자 세 종류 × 위치 순열: 144개 원국.
- 육합 여섯 종류 × 반복 두 글자의 위치 순열: 36개 원국, 각 육합 네 위치 쌍 보존.
- 중신·생지·성지 충, 조합 내부·외부 충의 근거와 자연어 표현 검증.
- 육합 여섯 종류의 독립 생·극 후보가 자동 억제되지 않는지 확인.
- 점수 0과 실제 적용량 `null` 구분, 성립 판정 재도입 거부.
- 실제 1990-01-08 18:00 원국의 중신 중복과 두 조합을 세 HTTP 경로에서 확인.
- 전체 회귀 검사 262개 통과. 기존 점수·통근과 내부 실험 모델 회귀 검사 포함.

주요 테스트는 `test_hap_presence_facts.py`, `test_root_response_contract.py`이며,
[표시 JSON 예시](relation_presentation_examples.json)도 현행 API로 다시 생성했다.
