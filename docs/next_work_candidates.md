## 추천 시작 범위

첫 작업은 기능 추가보다 **출생 시각 처리 기준의 코드·문서·사례 대조**를 추천한다.
생년월일시 계산은 모든 관계 조회의 입력이므로, 해설 확장보다 먼저 근거를 확인할 가치가 있다.
다만 현재 오류를 발견한 것은 아니며 기존 검증이 불충분하다고 단정하지 않는다.

현재 `birth_input_validation.md`에는 01:30 자시·01:31 축시가 기록돼 있고,
시간대·지역 보정·일주 전환 정책은 그 검증 작업에서 새로 정하지 않았다고 명시돼 있다.
일반적인 시각 기대와 다를 수 있으므로 서비스가 채택한 기준을 분명히 설명하는 것이 조사 목표다.

1. 입력 시각이 계산에 전달되는 경로와 고정 보정의 유무를 추적한다.
2. 23시·자정·01:30/01:31 및 절기 당일 경계에 기존 테스트·기대값이 있는지 확인한다.
3. 이미 검증된 항목은 반복 구현하지 않고 결과를 연결한다. 새 검증은 독립 근거가 있는 사례에 한정한다.
4. 현행 기준·검증 결과·근거 미확인 항목을 짧은 표로 정리한다. 정책 변경이 필요한 경우 별도 결정 후 수정한다.

일간·시주 변경을 초래하는 정책을 조사 중 임의로 바꾸거나 새 학파 규칙을 추가하지 않는다.
고 크기·개고, 개인별 종합 해석, 대량 LLM 생성은 이번 추천 범위에 포함하지 않는다.
