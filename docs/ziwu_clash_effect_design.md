# 子午충 세력 변화 계약 초안

상태: 子午충의 잠정 계산을 v3 독립 조립기에 연결했다. 현재 API의 출력은 변경하지 않았다. 계수와 충 이전 세력은 임상·구조 관계 검증 전 잠정값이다.

## 해석 기준

- 子午충의 일차 공격 방향은 **子→午**로 고정한다. 子와 午의 충 이전 세력은 월령·지장간·동주 천간·다른 지지의 인정된 작용을 반영한 값이다. 다른 기둥의 천간을 대상 지지의 직접 생극 입력으로 사용하지 않는다.
- 午가 받는 **일차 충격**과 子가 받는 **자기 손실**을 구분한다. 子의 자기 손실에는 공격 자체의 소모와 午의 저항 때문에 커진 손실을 함께 반영하되, 두 항목을 독립 피해량으로 출력하거나 중복 가산하지 않는다.
- 午의 저항이 강할수록 子의 자기 손실이 커질 수 있다. 이는 午가 子를 독립적으로 공격하거나 충의 일차 방향이 뒤집혔다는 뜻이 아니다. '역손상'은 필요할 때 이 손실이 커진 원인을 설명하는 말로 사용한다.
- 두 변화량은 모두 해당 지지에 대한 부호 있는 값이다. 손실이 확정되면 음수, 해당 효과가 없다고 판정되면 `0`, 아직 계산할 수 없으면 `null`이다. `null`을 `0`으로 바꾸지 않는다.

## v3 잠정 출력 형태

아래는 `甲甲甲甲 / 子午辰寅`의 연–월 충에서 **관련 필드만** 표시한 예시다. `directional_effects[]`의 잠재 강도·거리·빈주 필드는 생략했다. 실제 v3 스키마에는 `mechanism`, `candidate_loss_rate`, `self_effects`와 보정 정보가 포함된다.

```json
{
  "relation_id": "branch:clash:year:month",
  "activation_status": "active",
  "calculation_status": "provisional_calculated",
  "direction": {"from_pillar": "year", "to_pillar": "month"},
  "metrics": {
    "applied_formula_id": "branch:ziwu_clash_loss_rate_v0",
    "calibration_version": "ziwu_clash_0.1",
    "calibration_status": "provisional",
    "directional_effects": [
      {
        "from_pillar": "year",
        "to_pillar": "month",
        "mechanism": "primary_shock",
        "candidate_loss_rate": 0.016615,
        "applied_power_delta": -0.0412
      }
    ],
    "self_effects": [
      {
        "pillar": "year",
        "mechanism": "attacker_self_loss",
        "candidate_loss_rate": 0.081173,
        "power_delta": -0.0619
      }
    ]
  }
}
```

`direction`은 충의 **일차 공격 방향**만 뜻한다. `self_effects[].power_delta`는 해당 `pillar` 자신의 변화량이므로 `directional_effects[].applied_power_delta`의 `to_pillar` 계약에 억지로 넣지 않는다. 子의 자기 손실은 한 번만 적용한다. 午의 저항 세력과 손실 증가 이유는 계산 근거에 기록하되 별도 午→子 피해량으로 내보내지 않는다.

기존 v2 양방향 잠재 강도의 午→子 수치는 대칭 충 모델의 값이며 子의 자기 손실로 사용하지 않는다. v3의 子午충은 일차 공격 방향 한 건과 자기 손실 한 건으로 출력한다. 다른 충 조합은 조합별 공격 방향이 정해지지 않아 기존 잠재 양방향 상태를 유지한다.

## 계산 순서와 남은 검증

1. 대상 子午 쌍의 충격·자기 손실을 아직 적용하지 않은 세력을 고정한다. 다른 쌍의 미계산 구조 효과는 [v3 계획](./branch_dynamics_v3_plan.md)에 따라 `null`로 표시하며 현재 세력을 잠정 지표로 취급한다.
2. 子의 공격 세력과 거리, 午의 저항 세력으로 午의 충격률과 子의 자기 손실률을 구한다. 공격량이 0이면 두 손실 모두 0으로 계산한다.
3. 저항에 따른 손실 증가가 어느 지점부터 뚜렷해지는지 사례로 검토한다. 이것은 별도 '역손상' 피해의 성립 문턱이 아니라 자기 손실 산식의 형태를 정하는 문제다. 잠정 계수의 최종값과 상한은 사례 검토 후 정한다.
4. 같은 子가 여러 午와 충하면 각 쌍의 자기 손실을 기준 세력 범위 안에서 집계한다. 같은 午가 여러 子와 충할 때도 같은 방식으로 午 손실을 집계한다. 기존 대칭식의 `k` 비교표는 이 설계의 계수 근거로 사용하지 않는다.

## 시범 산식과 잠정 계수

충 이전 세력을 `P子`, `P午`, 거리 가중치를 `d`로 두고 `A = P子 × d`, `q = A / (A + P午)`로 둔다. 분모가 0이면 `q = 0`이다. `q`는 거리까지 반영한 子의 상대 공격 비중이며, 명리학에서 검증된 절대 척도가 아니다.

```text
午의 충격       = -P午 × k_shock × q²
子의 자기 손실 = -P子 × d × (k_base + k_resist × (1 - q))
```

`k_shock`은 午의 최대 손실 비율, `k_base`는 공격 자체의 작은 소모율, `k_resist`는 午 저항에 따른 추가 손실률을 조절한다. 잠정 범위는 `0 ≤ k_shock ≤ 1`, `0 < k_base`, `0 ≤ k_resist`, `k_base + k_resist ≤ 1`, `0 ≤ d ≤ 1`이다. 두 손실은 각각 자기 기준 세력을 넘지 않는다. `P子 = 0`이거나 `d = 0`이면 두 손실을 0으로 둔다. `q²`는 공격 우세에 따른 午의 손실 비율 차이를 드러내기 위한 시범 선택이며 근거 사례에 따라 바꿀 수 있다.

[관계 규칙의 子午충 항목](../services/relation_rules.py)에 잠정 시작값 `k_shock=0.30`, `k_base=0.02`, `k_resist=0.08`을 `calibration_version: ziwu_clash_0.1`, `status: provisional`로 둔다. v3 조립기는 이 값을 잠정 적용량에 사용한다. `k_shock=0.30`은 午의 손실률 상한을 30%로 제한하지만 보통 `q² < 1`이므로 실제 시범 손실률은 더 낮다. 인접 충에서 `k_base=0.02`는 공격 자체의 최소 소모율 2%, `k_resist=0.08`은 저항에 따른 최대 추가율 8%다. 즉 한 충에서 子의 시범 손실률은 10%를 넘지 않는다. 이 수치는 사례 비교를 위한 보수적인 초기값이며 임상적으로 검증된 계수가 아니다.

아래는 이 **잠정 계수**를 넣은 산술 예시다. 세력 2.0과 0.5는 실제 원국의 계산값이 아니다.

| 비교 상황 | `P子` / `P午` / `d` | 午 충격 | 子 자기 손실 | 午 손실률 / 子 손실률 |
| --- | --- | ---: | ---: | ---: |
| 子 강·午 약 | 2.0 / 0.5 / 1.0 | −0.0960 | −0.0720 | 19.2% / 3.6% |
| 子 약·午 강 | 0.5 / 2.0 / 1.0 | −0.0240 | −0.0420 | 1.2% / 8.4% |
| 첫 사례와 같은 세력의 격위 충 | 2.0 / 0.5 / 0.5 | −0.0667 | −0.0467 | 13.3% / 2.3% |

같은 子 세력에서 午의 저항 세력이 커지면 子의 손실률은 커지고 午의 손실률은 작아진다. 가까운 충보다 거리가 먼 충은 두 손실이 줄어든다. v3의 `applied_power_delta`에는 이 **잠정 계산값**을 기록하며 `calculation_status: provisional_calculated`와 보정 버전으로 확정값과 구별한다. 특히 현재 구조 관계의 독립 효과가 미계산인 경우 `P子`·`P午` 자체가 잠정값이다.

### 현행 계산기의 세력값 대입

다음 `P子`·`P午`는 현행 계산기의 해당 子午 쌍 `power_before`에서 읽었다. 손실은 위의 **잠정 계수**를 대입한 v3 시범 출력값이며 검증된 해석값은 아니다. 천간·지지는 연월일시 순서다.

| 원국 / 子午 위치 | `P子` / `P午` | `q` | 午 충격 (손실률) | 子 자기 손실 (손실률) |
| --- | ---: | ---: | ---: | ---: |
| `甲甲甲甲 / 子午辰寅`, 연–월 | 0.7628 / 2.4785 | 0.2353 | −0.0412 (1.66%) | −0.0619 (8.12%) |
| `甲癸甲甲 / 子午辰寅`, 연–월 | 0.7628 / 1.8851 | 0.2881 | −0.0469 (2.49%) | −0.0587 (7.70%) |
| `甲壬甲甲 / 午子辰寅`, 연–월 | 2.4332 / 0.8967 | 0.7307 | −0.1436 (16.02%) | −0.1011 (4.15%) |

첫 두 사례에서 월간이 甲에서 癸로 바뀌면 午의 기준 세력이 낮아지고, 시범식의 午 손실률은 커지며 子 손실률은 줄어든다. 셋째 사례는 子가 월지로 강한 경우다. 잠정 계수에서는 子의 **상대 손실률**뿐 아니라 절대 손실량도 午의 충격량보다 작다. 다만 이것을 모든 원국에 강제하는 규칙으로 정하지는 않았다. 손실률의 방향만 맞는다고 계수를 최종 확정하지 않는다.

`甲甲甲甲 / 子午午午`에서 연지 子의 쌍별 기준 세력은 모두 `0.8075`이고, 세 午의 기준 세력은 월 `2.6217`, 일 `1.9876`, 시 `1.3177`, 거리 가중치는 `1.0`, `0.7`, `0.5`다. 잠정식의 子 손실률은 차례로 약 `8.1162%`, `5.7601%`, `4.0618%`다. 곱셈 집계와 손실률 비례 배분을 적용하면 총손실 `0.1367`, 잔여 세력 `0.6708`, 쌍별 배분 `0.0618`·`0.0439`·`0.0310`이 나온다. 마지막 배분값에는 반올림 잔차 `0.0001`이 포함되어 세 값의 합이 총손실과 정확히 일치한다. 자기 손실 항목에 대한 집계의 해석 적합성은 임상 사례로 계속 검토한다.

이 시작값은 세력 우열에 따른 **상대 손실률**을 우선 비교해 정했다. 강한 子의 절대 손실량이 항상 午의 충격량보다 작아야 한다는 조건은 채택하지 않았다. 다른 원국·계절·관계 중첩 사례에서 나타나는 손실 크기를 임상 판단과 대조한 뒤 세 계수를 각각 조정한다.

### 추후 계수 조정 절차

1. 사례마다 원국, 적용한 규칙 버전, 충 이전 `P子`·`P午`, 거리, 동주 천간과 주변 지지의 세력 근거를 함께 보존한다. 구조 효과가 미계산이면 그 상태도 표시한다.
2. 午 손실률과 子 손실률에 대한 해석상 기대 순서와 허용 범위를 먼저 기록한다. 사례에서 손실량을 직접 관측한 것처럼 취급하지 않는다.
3. `k_shock`, `k_base`, `k_resist`를 [관계 규칙](../services/relation_rules.py)의 한 항목에서 조정하고, 기존 기준 사례와 다중 午 사례의 손실률·상한·순서를 다시 비교한다. 계수를 수정하면 `calibration_version`을 갱신하고, 식의 형태까지 바꾸면 `formula_id`도 갱신한다.
4. 서로 충돌하는 사례가 있으면 계수를 억지로 맞추기 전에 기준 세력, 구조 관계 중복, 산식의 형태를 검토한다. 충분한 사례가 쌓이기 전까지 상태는 `provisional`로 유지한다.

## 검증 기준 사례

| 상황 | 확인할 판단 |
| --- | --- |
| 子 강, 午 약 | 子→午 충격은 유지하고 子의 작은 자기 손실을 한 번만 표시한다. |
| 午가 월지이고 木의 생을 받음, 子에 金 생조 없음 | 午의 저항 근거와 子의 지원 부재를 구분하고 子의 자기 손실 증가를 검토한다. |
| 子가 金의 생조를 받고 午가 제약받음 | 공격 세력과 저항 세력의 변화가 충격과 자기 손실에 어떻게 반영되는지 확인한다. |
| 子가 여러 午와 충 | 각 쌍의 자기 손실을 중복 가산하지 않고 子의 총손실이 기준 세력을 넘지 않는지 검증한다. |

현재 [관계 규칙](../services/relation_rules.py)은 子午충의 **잠재 강도** 양방향 계수를 모두 `1.0`으로 유지하고, 별도로 위의 잠정 손실률 계수를 기록한다. [v3 모델](../schemas/branch_dynamics_v3.py)과 [v3 조립기](../services/branch_dynamics_v3_assembler.py)는 두 손실을 구분한다. 현재 `branch_strengths.effective_power`는 충 손실을 반영하기 전 값이며 구조 관계의 독립 효과도 미계산이다. 지지의 최종 세력으로 사용하지 않는다.
