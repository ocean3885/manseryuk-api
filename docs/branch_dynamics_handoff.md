# 현재 작업 재개 안내

현행 개발 기준과 문서 우선순위는 [문서 안내](README.md)에 정리했다. 입력·오류·기간 선택·관계 조회의 최신 계약을 먼저 읽는다.

최근 API 정리·관계 근거 개선과 다음 검토 지점은
[2026-11-13 작업 재개 기록](current_work_handoff.md)에 정리했다.

현재는 관계 정보의 완전성과 API 계약을 보강한다. 통근 영향과 최종 세력·손상률은 미평가 상태를 유지한다. 과거 계획을 근거로 계수 추정이나 수치 계산을 자동 재개하지 않는다.

이 경로에 있던 상세 변경 이력은 [중단 연구 인수인계 기록](archive/strength-research/branch_dynamics_handoff.md)으로 보존했다. 그 기록의 “다음 작업”은 현행 지시가 아니다.
