# 지지 작용 작업 이어받기

작성일: 2026-10-31

## 현재 기준

- 최종 출력 목표는 [branch_dynamics_v3.json](./branch_dynamics_v3.json), 구현 순서는 [branch_dynamics_v3_plan.md](./branch_dynamics_v3_plan.md)를 따른다. 목표 JSON은 주석이 포함된 설계 샘플이며 현재 API 응답이 아니다.
- 실행 규칙의 원본은 [relation_rules.py](../services/relation_rules.py)다. 현재 v2 규칙 버전은 `2.19.0`, v3 잠재량·쌍별 생극 억제 정책 버전은 `3.8.0-draft`다.
- 사용자 최신 결정: 파 후보는 `子卯`, `卯午`, `午酉` 세 쌍이다. `子卯`는 형 후보에서 제외하고 파로만 탐지한다. `子卯`와 `卯午`의 생도 다른 쌍과 같이 파가 `active`로 확정될 때만 억제한다.
- 천 후보는 `子未`, `丑午`, `寅巳`, `卯辰`, `申亥`, `酉戌` 여섯 쌍이다.
- 삼형은 `寅巳申`, `丑戌未`의 세 지지가 있으면 거리와 무관하게 `active` 그룹으로 기록한다. 쌍별 형은 `丑戌`, `戌未`와 辰·午·酉·亥 자형을 기록한다. 자형은 동일 글자가 인접하면 `active`, 격위면 `candidate_only`다. `寅巳申`의 세 쌍은 각각 천·충·육합, `丑未`는 충으로 기록한다. 삼형은 구성 쌍의 성립 상태와 잠재 강도를 바꾸지 않는다.
- `午未` 육합의 후보 오행은 土다. 후보 오행은 실제 합화 판정이 아니다.

## 구현 상태

- [branch_relations.py](../services/branch_relations.py)와 [interaction_matrix.py](../services/interaction_matrix.py)는 관계 후보를 위치별로 탐지한다. 파·충·천·쌍별 지세형은 거리와 무관하게 `active`, 육합은 인접 충 개입이 없을 때 `active`로 기록한다. 육합의 충 개입 조건과 삼합의 조건 판정은 유지한다.
- [branch_dynamics.py](../services/branch_dynamics.py)는 월령·동주 천간·주변 지지를 반영한 지지별 상대 세력과 쌍별 잠재 작용을 산출한다.
- [branch_dynamics_v3_assembler.py](../services/branch_dynamics_v3_assembler.py)는 v2 결과에서 v3의 지지별 근거, 여섯 위치 쌍, 그룹, 경합 후보를 조립한다. 성립한 쌍별 구조는 활성 목록에, 같은 쌍의 생·극은 억제 목록에 넣는다. 방향별 `interaction_intensity`는 잠재량이고 `applied_power_delta`는 아직 대부분 미확정이다. 삼형 그룹의 독립 강도와 방향도 미정이다.
- `.venv312/bin/python -m unittest discover -s tests`로 회귀 테스트를 실행한다. 가상환경 Python은 일부 샌드박스에서 경로가 보이지 않을 수 있으므로, 그 경우 호스트 실행 권한이 필요하다.

## 2026-10-31 진행 상황

- [지지 관계 후보 전수 검토](./branch_relation_candidate_audit.md)를 작성했다. 서로 다른 쌍 66개와 같은 지지 쌍 12개를 모두 기록했고, 양방향 위치 검사 156건에서 규칙표와 실제 탐지 결과의 불일치는 없었다.
- 구조 후보 42쌍 중 `primary_relation`이 명시된 것은 15쌍이다. [전수 검토표](./branch_relation_candidate_audit.md)에 27쌍의 처리 결론을 기록했다. 이 필드는 v2의 정적 기본 분류 메타데이터이며, 실제 성립·우세는 v3 `interaction_resolution`에서 다룬다. 미지정 27쌍을 유형 이름으로 자동 채우지 않는다.
- 사용자 결정에 따라 여섯 천 관계의 출력 용어를 `천(穿)`으로 통일했다. v3 관계 유형은 `pierce`와 표시명 `천`을 사용한다.
- [성립 판정 현황표](./branch_relation_activation_review.md)에 子午·寅亥·寅巳·子卯 사례와 子卯·卯午 선제 생 차단 제거 결정을 기록했다.
- 子卯·卯午의 생 선제 차단을 제거하고 파·충의 공통 성립 기준에 연결했다. 파·충이 `active`인 쌍의 생·극은 후보로 남기되 독립 적용량 0, 주변 세력 보정 0이다.
- 사용자 결정: 파·충은 해당 두 지지가 원국에 있으면 거리와 무관하게 성립한다. 거리는 작용 강도에 반영한다. [성립 판정 기록](./branch_relation_activation_review.md)에 구현 결과와 남은 과제를 기록했다.
- 사용자 결정: 천과 두 지지의 지세형도 글자 존재만으로 `active`다. 육합은 인접 충 개입 조건을 유지하면서 조건이 없으면 `active`다. 삼형·자형은 후보로 남겨 별도 성립 조건을 결정한다.
- 사용자 결정: 삼형은 세 글자가 모두 있으면 떨어져 있어도 `active` 그룹이다. 쌍별 천·충·육합·형은 각각의 성립 조건에 따라 유지하며, 삼형 그룹의 독립 세력 증감은 산출하지 않는다.
- 사용자 결정: 자형은 같은 辰·午·酉·亥가 붙어 있는 위치 쌍만 `active`다. 떨어진 같은 글자는 후보로 보존하며, 세 글자가 반복되면 세 위치 쌍을 각각 판정한다. 자형의 독립 점수와 적용량은 아직 계산하지 않는다.
- 사용자 결정: v3 `directional_effects[].applied_power_delta`는 `to_pillar`가 받는 세력 변화량이다. 음수는 약화, 양수는 강화, 0은 해당 방향 독립 작용 없음이다. `target_exposure`는 잠재 지표이며 실제 변화량에 바로 대입하지 않는다. 충의 산식과 다중 관계 합산 기준은 아직 미정이다.
