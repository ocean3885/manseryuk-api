[기존·신규 통합 테스트](../tests/test_xu_shi_integration.py)를 포함한 Python 3.12 전체 회귀 **174건 통과**, 계약 JSON 예시도 유효하다. `ROOT_STRENGTH` 계수·지지 위치 가중치·실 경계 `0.5`와 뿌리 전부 제외 규칙은 임시값 그대로다.

**2026-11-04 후속 결정:** 동주 통근 여부는 `ROOT_STRENGTH[천간][동주 지지] > 0`으로 명시하고, 동주 점수에서 지지 위치 가중치를 제거했다. 위치·거리 가중 계산은 타주 지원과 전주 v1 회귀 옵션에만 남는다. [원국 분석](../services/analysis.py)의 `same_pillar_root_exists` 및 [관계 조회](../schemas/character_relation_index.py)의 `has_same_pillar_root`를 추가했다. 현행 허실 규칙은 `2.1.0`, 조회 계약은 `1.5-draft`이며 Python 3.12 전체 회귀 **175건 통과**. 다음 검토 대상은 잠정 실 경계 `0.5`와 활성 관계에서 동주 뿌리 전체를 제외하는 규칙이다.

**2026-11-04 동주 허실 경계 제거:** 사용자 결정으로 현행 동주 프로필은 `0.5`를 쓰지 않는다. 동주 계수 양수는 약한 통근이어도 실이며, `0`은 기존 명칭 허투를 유지한다. 활성 관계로 잔여 기여도가 계산상 `0`이 되면 변허다. 강도 계수와 타주 지원은 별도 기록한다. 천간 동주 통근 개수만으로 원국 신강·신약을 단정하던 요약도 동주 통근/무근 개수와 전체 강약 미판정으로 바꿨다. Python 3.12 전체 회귀 **179건 통과**. 남은 검토는 통근 계수표의 인정 조합과 충·형·천에서 동주 뿌리를 전부 제외하는 잠정 가정이다.

## 현재 기준

- 최종 출력 목표는 [branch_dynamics_v3.json](./branch_dynamics_v3.json), 구현 순서는 [branch_dynamics_v3_plan.md](./branch_dynamics_v3_plan.md)를 따른다. 목표 JSON은 주석이 포함된 설계 샘플이며 현재 API 응답이 아니다.
- 실행 규칙의 원본은 [relation_rules.py](../services/relation_rules.py)다. 현재 v2 규칙 버전은 `2.19.0`, v3 잠재량·쌍별 생극 억제·子午충 잠정 계산 버전은 `3.9.0-draft`다.
- 사용자 최신 결정: 파 후보는 `子卯`, `卯午`, `午酉` 세 쌍이다. `子卯`는 형 후보에서 제외하고 파로만 탐지한다. `子卯`와 `卯午`의 생도 다른 쌍과 같이 파가 `active`로 확정될 때만 억제한다.
- 천 후보는 `子未`, `丑午`, `寅巳`, `卯辰`, `申亥`, `酉戌` 여섯 쌍이다.
- 삼형은 `寅巳申`, `丑戌未`의 세 지지가 있으면 거리와 무관하게 `active` 그룹으로 기록한다. 쌍별 형은 `丑戌`, `戌未`와 辰·午·酉·亥 자형을 기록한다. 자형은 동일 글자가 인접하면 `active`, 격위면 `candidate_only`다. `寅巳申`의 세 쌍은 각각 천·충·육합, `丑未`는 충으로 기록한다. 삼형은 구성 쌍의 성립 상태와 잠재 강도를 바꾸지 않는다.
- `午未` 육합의 후보 오행은 土다. 후보 오행은 실제 합화 판정이 아니다.
