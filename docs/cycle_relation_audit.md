# 대운·세운 관계의 누락·중복 감사

검토일: 2026-11-04. 등록된 후보 규칙의 추출·연결·재조립을 점검했다. 운 관계의 실제 성립, 영향·통근 손상 규칙은 변경하지 않았다.

## 검증 범위

| --- | --- |

기존 등록 후보 추출에서 새로 확인된 누락은 없었다. 다음 재조립 문제와 계약 검증의 빈틈을 보강했다.

## 발견한 문제와 수정

1. `attach_cycle_relations`를 같은 그래프에 다시 적용하면 `not_evaluated_mechanisms`가 중복됐다. 순서를 보존하면서 중복을 제거한다.
2. 소속을 제거하거나 글자를 변경한 뒤 재조립하면 `.update()`만 수행해 이전 운 관계가 남을 수 있었다. 기존 `cycle:` 관계를 교체하고 모든 글자의 역참조·투간 참조를 다시 구성한다. 원국 관계는 보존한다.
3. 직렬화 후 재조립 시 출처의 선택 필드 `relation_id=null` 유무가 달라 결과가 달라졌다. 탐지기에서도 명시적으로 제공해 원본·직렬화·재조립 결과를 일치시킨다.
4. 생성 중 동일 ID에 서로 다른 본문이 겹치면 마지막 결과로 덮어쓸 수 있었다. 충돌을 오류로 처리한다. 현재 규칙표의 정상 출력에는 충돌이 없었다.
5. 공통 그래프 모델은 참조 연결은 검사했지만 운 관계의 종류·참여 글자 수·정규 ID·상태·투간 의미는 일부 검사하지 않았다. `cycle:` 관계 전용 검증으로 강화했다. 천간/지지 혼용, 다자 관계의 조합, 투간 출처·대상·정확 일치, 방향 근거, 미평가 사유를 검사한다.

재조립은 관계·글자 참조·범위만 갱신한다. 소속·선택 자체를 바꾸는 호출자는 선택 메타데이터도 갱신해야 한다. 공개 조회 API는 매 요청 새 그래프를 만들므로 이 변경은 정상 응답의 관계 종류나 ID를 바꾸지 않는다.
