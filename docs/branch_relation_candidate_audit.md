# 지지 관계 후보 전수 검토

작성일: 2026-10-31. 후보 전수 검사의 기준은 [실행 규칙](../services/relation_rules.py) v2 `2.14.0`이며, 이후 v2 `2.15.0`에서 子卯·卯午의 선제 생 차단을 제거하고 v2 `2.16.0`에서 파·충의 자동 성립을 추가했다. 구조 후보 목록은 그대로다. 현재 정책은 [성립 판정 기록](./branch_relation_activation_review.md)을 따른다.

## 범위와 검사 결과

12지지의 서로 다른 쌍 66개와 같은 지지 쌍 12개, 총 78개를 검사했다. 표의 구조 후보는 두 지지만 놓은 기본 후보이며, 네 지지 원국의 삼합·방합·삼형, 인접 충, 중신 중복에 따라 실제 출력 상태가 달라질 수 있다. `생·극·동기`는 지지 대표 오행의 경로이며 구조 관계와 별도로 계산된다. `주관계`는 [PAIR_ACTION_RULES](../services/relation_rules.py)에 현재 명시된 정적 기본 분류다. `미지정`은 관계 부재나 실제 불성립 판정이 아니다.

규칙표의 후보와 [탐지 함수](../services/branch_relations.py), [상호작용 매트릭스](../services/interaction_matrix.py)의 연·월 위치 출력이 같은지 각 쌍의 정방향·역방향 156건을 비교했다. **불일치 0건**이다. 따라서 이번 검토에서 후보 조합 자체의 코드 오류는 발견되지 않았다. 이 검사는 두 글자만 반복한 원국을 이용했으므로, 다른 글자가 합·충·삼자 구조의 성립 상태를 바꾸는 경우까지 검증한 것은 아니다.

## `primary_relation` 검토 결론

- [v2 쌍별 결과](../services/branch_dynamics.py)의 `primary_relation`은 [PAIR_ACTION_RULES](../services/relation_rules.py)에 명시된 15쌍의 **정적 기본 분류 메타데이터**로 해석한다. 관계의 실제 성립, 최종 주도권, 강한 지지가 작용하는 방향을 뜻하지 않는다.
- 실제 사례 `甲甲甲甲 / 申寅亥子`에서 월–일 寅亥의 `primary_relation`은 `육합(六合)`이지만 같은 육합 관계의 `activation_status`는 `conditional`이다. 따라서 기본 분류를 실제 활성 관계로 읽을 수 없다.
- 나머지 27쌍의 `null`은 **조합별 기본 분류 규칙을 아직 명시하지 않았음**을 뜻한다. 탐지된 `relations[]`가 없다는 뜻은 아니다. 반합 8·공합 4·암합 3·충 3·천 5·자형 4에 유형 이름을 기계적으로 복사하지 않는다. 특히 공합·암합·자형은 v3에서 성립·계량을 유보하는 후보이고, 완성 삼합의 내부 반합은 구조 근거로만 남는다.
- [v3 쌍별 모델](../schemas/branch_dynamics_v3.py)은 `primary_relation`을 출력하지 않고 관계 후보를 각각 기록한다. 실제 선택·억제·미해결은 [interaction_resolution](../services/branch_dynamics_v3_assembler.py)에서 다룬다. 현재 파·충은 별도 성립 규칙으로 `active`가 되지만, `primary_relation`의 정적 분류만으로 다른 관계를 활성화하지 않는다.
- 따라서 이번 단계에서는 27쌍을 자동으로 채우거나 수치 우세로 대체하지 않는다. 이후 조합별 근거가 검증되면 [규칙표](../services/relation_rules.py)에 정적 분류를 명시할 수 있으나, 실제 적용 판정은 별도 단계로 유지한다.

## 다음 판정 과제

1. **용어 통일 완료.** 사용자 결정에 따라 여섯 조합의 출력 유형을 `천(穿)`으로 통일하고 v3 관계 유형을 `pierce`로 지정했다.
2. **중첩과 성립 조건을 검토한다.** 子卯·卯午의 파와 생 경로는 둘 다 잠재 후보로 남긴다. 파가 `active`로 확정될 때만 같은 쌍의 생을 억제한다. 다른 충·천·합과 생·극이 겹칠 때의 적용 여부, 삼합·방합·삼형이 쌍 관계에 미치는 효과는 아직 전수 판정되지 않았다. 잠재 강도를 실제 적용량으로 옮기기 전에 조합별 근거를 확정한다.

이번 표는 현재 구현의 전수 목록이다. 학파 전체의 정설이나 관계별 실제 성립을 검증했다는 뜻은 아니다.
