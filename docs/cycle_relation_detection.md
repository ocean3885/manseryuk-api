# 원국·대운·세운의 소속 간 관계 탐지

`/cycle-analysis`는 선택된 원국↔대운, 원국↔세운, 대운↔세운의 쌍별 관계와 여러 소속이 참여하는 삼합·방합·삼형 후보를 함께 제공한다. 첫 대운 이전 세운은 원국↔세운만 탐지한다. 기존 원국 관계는 재계산하지 않고 보존한다.

## 탐지 규칙

| 대상 | 제공 종류 | 상태 |
| --- | --- | --- |
| 천간 쌍 | 등록된 합·충 | `candidate_only` |
| 천간 쌍 | 등록된 극과 방향 | `detected` |
| 지지 쌍 | 육합·충·천·파·형·자형·반합·공합·암합 | `candidate_only` |
| 지지 쌍 | 생·극의 오행 방향, 같은 지지 반복 | `detected` |
| 지지 세 위치 | 삼합·방합·삼형 | `candidate_only` |
| 지지→천간 | 상세 지장간과 정확히 같은 천간의 투간 | `detected` |

후보표는 `services/relation_rules.py`를 재사용한다. 파는 프로젝트의 `BREAKS`이며 별도 `TRADITIONAL_BREAKS`를 합쳐 사용하지 않는다. 천간극은 등록된 `STEM_RESTRAIN`만 탐지한다. 천간 생·동오행과 일반적인 다른 소속 천간↔지지 오행 관계는 확장하지 않았다. 투간은 `JIJANGGAN_DETAILED`의 정확한 글자 일치이며 같은 오행의 다른 글자는 포함하지 않는다.

`detected`는 글자 일치·표의 관계·오행 방향을 확인했다는 뜻이다. 실제 작용이나 우세를 확정한 상태가 아니다. 모든 운 관계는 `cycle_presence_only_activation_and_impact_not_evaluated` 사유를 갖는다. 운에 원국의 인접·거리·충 개입·그룹 경합 규칙을 그대로 적용하거나 `active`로 승격하지 않는다. 합화, 부분 억제, 작용량, 손상률, 통근 소멸도 계산하지 않는다.

## 위치와 중복

운 관계의 ID는 `cycle:{분류}:{종류}:{정렬된 참여 글자 ID들}`이다. 입력 사전 순서에 영향받지 않으며 같은 글자도 소속·위치가 다르면 구분한다. 투간·극·생의 방향은 `direction`에 별도 보존한다.

세 위치 조합이 등록된 다자 구조를 이루고 최소 두 소속이 포함되면 위치별 관계를 발행한다. 원국에 동일 지지가 두 위치에 있어 운과 각각 구조를 이루면 두 관계로 보존한다. 이는 힘을 두 번 더한다는 의미가 아니다. `formation_candidates`는 그 관계의 위치 조합을 기록한다. 겹치는 구조의 선택·가산·억제는 미평가다. 완성 그룹이 있어도 반합 후보를 삭제하거나 독립 작용으로 확정하지 않는다.

원국끼리의 관계와 운 한 기둥 내부 관계는 새 탐지기에서 제외한다. 기존 원국 관계 본문은 보존하고 새 관계의 모든 참여 글자에 역참조를 추가한다. 프론트엔드는 `context_ids`로 원국↔대운/원국↔세운/대운↔세운/복합 다자 관계를 분류한다.

## 범위와 근거

운 소속의 `calculation_status` 및 `selection.cycle_relations_status`는 `candidates_detected`다. 소속 단위 `calculated_scopes`는 후보 탐지에 참여했는지를 표시한다. 미확정 범위는 다음처럼 별도로 제공한다.

- `cycle_relation_activation`: 성립 조건
- `cycle_relation_competition`: 중첩·경합·억제
- `cycle_power_effects`: 실제 세력 변화·통근 영향
- `cycle_rooting`: 운 글자의 통근
- `cycle_internal_relations`: 운 한 기둥 내부 관계
- `cross_context_stem_branch_element`: 소속 간 일반 천간↔지지 오행 관계

`source_refs.system=cycle_relation_rules`는 원본 후보표의 모듈 위치를 가리킨다. `rule_ids`에는 운 탐지 규칙 `1.0.0-draft`와 재사용 후보표 버전을 함께 기록한다. 기존 원국의 `source_refs`는 변경하지 않는다. 관련 관계가 늘어도 원국 통근 점수·상태·영향 미평가를 유지한다.

검증 범위는 천간 100개·지지 144개 순서 조합, 등록된 다자 구조 전체와 반복 위치, 세 소속 참여, 순서 독립 ID, 정확 일치 투간, DB·HTTP 및 기존 원국 회귀다. 후보표와 구현의 대응을 검증하며 운 성립 규칙의 명리적 정확성을 승인하는 검사는 아니다.
