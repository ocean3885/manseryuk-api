# 지지별 작용 후 세력의 계산 완성 조건

상태: **3.4-draft 출력의 보수적 판정 기준**. [목표 출력](./branch_dynamics_v3.json)의 `post_effect_power`를 언제 숫자로 내보낼 수 있는지 정의한다. [차단 근거 수집기](../services/branch_post_effect_gate.py)는 현재 출력에 드러난 미해결 관계·그룹·출처 경로를 지지별로 모으고, [v3 계약 검사기](../schemas/branch_dynamics_v3_contract.py)는 집계식이 없는 현 단계의 숫자 출력을 거부한다. 최종 세력 산식이나 지장간 손실량을 계산하는 문서가 아니다.

## 두 관문을 모두 통과해야 숫자가 된다

1. **작용 범위의 완성:** 해당 지지에 영향을 줄 수 있는 관계·그룹·출처 경로에서 성립·차단·적용량·대체 경로가 모두 결정돼야 한다. 미해결 경로가 있으면 `post_effect_status: incomplete`, `post_effect_power: null`이 적절하다.
2. **집계 근거의 완성:** 충 이전 기준값, 실제 포함·대체·제외된 경로 ID, 각 적용량의 단위와 합계, 다중 작용 배분·반올림, 사용한 공식·보정 버전을 보존해야 한다. 이 자료가 없으면 차단 항목이 없더라도 숫자를 출력하지 않는다.

현재 두 번째 관문의 집계기와 추적 필드가 없다. 따라서 실제 [v3 조립기](../services/branch_dynamics_v3_assembler.py)는 네 지지 모두 `null / not_calculated`를 출력한다. 계약 검사는 `provisional`·`resolved`에 숫자를 넣더라도 차단 항목이 있으면 거부하며, 차단 항목이 없어도 **집계식과 전체 기여 근거가 없다는 이유로 거부**한다. `incomplete`는 미해결 항목이 실제 있을 때만 `null`과 함께 쓸 수 있다.

## 현재 차단 근거의 범위

| 입력 | 차단하는 경우 | 별도 차단으로 세지 않는 경우 |
| --- | --- | --- |
| 쌍별 관계 | 참여 지지의 `active` 관계에 적용량이 미계산이거나 `potential`·`conditional`인 경우 | 근거와 함께 `suppressed`된 관계, 독립 작용량 없는 `structural_only`, `candidate_only`·`detected` 구조 사실 |
| 쌍별 잠정 적용량 | 子午충처럼 `active / provisional_calculated`인 관계는 잠정 근거 ID로 남김. 그 관계 하나만은 **미계산 차단 항목이 아님** | 잠정값을 곧바로 지지별 최종 세력에 빼지 않음. 같은 지지의 다른 미해결 관계·구조는 계속 차단 |
| 삼합·방합·삼형 | `potential`·`conditional`·`active` 그룹의 실제 성립 조합에 참여한 지지. 그룹 독립 기여 또는 내부 경합이 미해결 | `suppressed` 그룹의 그룹 ID 자체. 살아남은 별도 반합·충 등은 각자 판정 |
| 출처 경로 | 대상 지지의 `accounting_decision: undetermined`, 또는 아직 집계에 반영하지 않은 `replace`·`separate_effect` | 이미 반영된 일반 배경 `include`, 근거 있는 차단 `exclude`. 겹침 ID만 존재한다고 자동 대체하거나 자동 합산하지 않음 |
| 경합 결과 | 실제 억제 목록에 들어간 관계·그룹은 해당 후보의 차단 근거에서 제외 | 억제와 별개로 남은 활성 관계·구조 경로는 계속 검사 |

차단 근거는 `{ref_id, reason}`으로 내부에서 반환한다. `ref_id`는 실제 쌍 관계·그룹·출처 경로 ID이므로 사용자가 어떤 판단이 미해결인지 추적할 수 있다. 같은 충이 관계 적용량과 구조 경로 양쪽에 나타나면 **서로 다른 미완성 단계**로 기록될 수 있으며, 두 피해량을 합산한다는 뜻이 아니다.

## 원국별 확인 결과

| 원국 | 확인한 차단 근거 | 결론 |
| --- | --- | --- |
| A `乙己己庚 / 巳丑未午` | 월 丑과 일 未 모두 丑未충의 적용량이 미해결. 일 未에는 巳午未 방합과 그룹 출처 경로도 미해결 | 丑·未의 최종 세력을 숫자로 출력할 수 없음 |
| D `庚己丙乙 / 申丑申未` | 월 丑·시 未의 충 적용량 미해결. 현재 그룹 목록은 없고, 두 申의 入墓는 [검토 사례](./chouwei_a_d_source_paths.md)에만 있음 | 최종 세력 숫자 불가. **미탐지된 入墓 기전은 현재 차단 목록만으로 발견할 수 없다는 한계**가 있음 |
| `甲甲甲甲 / 子午辰寅` | 子午충은 잠정 적용량과 자기 손실을 갖지만, 같은 지지의 다른 잠재 관계·구조 경로가 남음 | 충 하나의 잠정 손실을 `effective_power`에서 빼서 최종값으로 발표하지 않음 |
| `甲甲甲甲 / 巳亥卯未` | 깨져 `suppressed`된 삼합의 그룹 ID는 차단하지 않음. 남은 충·반합·다른 경로는 별도 검사 | 그룹 억제만으로 네 지지의 최종 세력이 완성되지는 않음 |
| `甲甲甲甲 / 丑丑丑丑` | 현재 차단 목록이 비어 있음 | 그래도 집계 추적·기준 세력 검증이 없으므로 `resolved` 숫자를 허용하지 않음 |

## 지금 검사할 수 없는 완성도

차단 목록은 **이미 모델이 탐지해 출력한 경로**만 검사한다. D의 두 申이 丑에 들어가는 기전처럼 아직 규칙·후보 탐지에 없는 경로는 목록에 나오지 않는다. 그러므로 `차단 목록 비어 있음`은 `명리 해석에 필요한 모든 기전이 모델에 있음`을 뜻하지 않는다. 향후에는 지원하는 관계 유형·입묘/지장간 기전의 **모델 적용 범위**와 사례 검증 상태도 최종 세력의 집계 근거에 포함해야 한다.

또한 현행 `effective_power`의 계수는 [잠정 세력 계약](./branch_strength_accounting.md)상 미보정 상대 지표다. 모든 작용량을 산출하더라도 계수가 잠정이면 `resolved`보다 `provisional`이 맞다. 숫자를 허용할 때는 대체된 일반 보정을 원래 기준값에서 어떻게 제거했는지, 구조 효과가 같은 출처를 다시 쓰지 않았는지 검증해야 한다.

## 다음 구현 순서

1. 지지별 집계 추적의 최소 필드(기준값, 포함·제외·대체된 경로 ID, 적용량, 공식/계수 버전, 모델 적용 범위)를 [집계 추적 설계안](./branch_post_effect_trace_contract.md)에 정했다. 다음은 `not_calculated`·`incomplete`용 내부 골격부터 검증하는 일이다. 한 글자의 결과를 다른 글자의 미해결 관계 때문에 무조건 유보하지 않도록 대상별 경계를 유지한다.
2. [A·D 검토](./chouwei_a_d_source_paths.md)와 다른 충 사례에서 누락된 구조·지장간 기전의 탐지 범위를 확정한다. 새로운 기전은 먼저 후보·근거로 표시하고 임의 손실률을 부여하지 않는다.
3. 집계기가 출처 중복·상한·반올림을 검증한 뒤에만 `post_effect_status: provisional` 또는 `resolved`를 발행하도록 계약을 확장한다.
