# 루트 요약과 상세 자료의 정합성

2026-11-13. `analysis.summary`가 실제 상세 관계를 위치별로 요약하도록 정리했다.
기본 `/` 응답의 요약을 유지하며 별도 API나 요약 카드·점수는 추가하지 않았다.

## 확인한 문제

- 상대 글자만 적고 위치를 생략해 반복 글자의 서로 다른 관계가 같은 문자열로 합쳐졌다.
  `子午午午`에서 년지 子의 충 상대 세 위치가 `년지 충(午)` 하나로 축약됐다.
- 같은 쌍의 관계가 양쪽 기준 글자의 설명으로 반복됐다. 천간극도 극함·극당함이 별도 행이었다.
- 같은 삼합·방합·삼형이 참여 글자마다 반복돼 그룹 수와 실제 세 자리 조합 수를 구별하기 어려웠다.
- `total_energy_balance`는 실제로 동주 통근 개수만 설명해 필드명과 계산 범위가 달랐다.
- `interactions.summary_list`는 `matrix[].description`을 그대로 복제한 목록이었다.

## 현재 `analysis.summary`

| 필드 | 반환 내용 |
| --- | --- |
| `branch_interactions: string[]` | 지지 간 관계별 위치·글자·일간 기준 십성을 포함한 요약 |
| `stem_interactions: string[]` | 천간 간 관계별 위치·글자·십성을 포함한 요약. 극은 방향 보존 |
| `rooting_summary: string` | 네 천간의 동주 통근·동주 무근 개수와 원국 신강·신약 미판정 안내 |

기존 `total_energy_balance`는 제거했다. 새 필드의 값도 원국 전체 강약을 판정하지 않는다.
자합·투간은 기존 상세 자료에서 조회한다. 위 두 관계 목록은 각각 지지 간·천간 간 관계 범위다.

요약은 `analysis.details`에 사용되는 원자료를 만든 뒤 그 자료에서 직접 조립한다.
관계를 다시 탐지하거나 통근·세력 점수를 다시 계산하지 않는다.
같은 쌍의 역방향 조회를 합치되 실제 참여 위치가 다르면 별도 관계로 보존한다.
지지 쌍에서는 종류가 다르면 같은 위치여도 별도로 남긴다.

천간극은 실제 극하는 위치 → 극당하는 위치로 표시한다. 일간 자신의 십성 표기는 `일간`이다.
삼합·방합·삼형은 참여 위치의 합집합을 한 줄에 적고 실제 세 자리 조합 수를 함께 제공한다.
반복 글자가 네 위치에 있어도 이를 네 글자로 구성된 하나의 삼합이라고 해석하지 않는다.
동일 입력의 요약 순서는 참여 위치·종류에 따라 결정되며 기둥 사전과 관계 목록의 나열 순서에 의존하지 않는다.

합화·길흉·피해를 단정하지 않는다. 육합·삼합은 조합의 존재와 후보 오행,
반합·방합·공합·암합은 후보 정보로 표시한다. 격위 자형은 후보임을 표시한다.
기존 탐지·성립 상태와 미평가 정책은 상세 자료에 그대로 유지한다.

## 중복 목록 제거

`advanced_analysis.interactions`는 `rule_version`과 `matrix`만 반환한다.
`summary_list`를 제거했고 반환 계약 버전을 **`3.0.0`**으로 변경했다.
지지 실행 규칙 `2.22.0`과 빈주 `4.0.0`은 유지했다.
관계별 설명은 기존 `matrix[].description`에서 조회한다.
기존 상호작용 프롬프트도 해당 설명을 직접 사용하며 문구와 선택 순서는 유지한다.
새 프롬프트나 LLM 해석 로직은 추가하지 않았다.

다른 반복 구조도 점검했다. 원국표의 십성·신살 이름 맵, 대운 선택 정보,
세운 첫 10개와 100개 목록, 글자별 양방향 원자료는 각각 조회 목적이 달라 유지했다.
특히 글자별 관계를 양쪽에서 조회하는 것과 전체 요약에 같은 관계를 두 번 적는 것은 구분했다.

## 예시

천간 `甲甲甲甲`, 지지 `子午午午`의 충 요약은 서로 다른 세 쌍이다.

```text
년지 子(정인) · 월지 午(상관): 충 관계
년지 子(정인) · 일지 午(상관): 충 관계
년지 子(정인) · 시지 午(상관): 충 관계
```

천간 `甲戊戊戊`, 지지 `子子子子`의 천간극 요약은 다음 세 방향을 보존한다.

```text
년간 甲(편관) → 월간 戊(비견): 천간극 관계
년간 甲(편관) → 일간 戊(일간): 천간극 관계
년간 甲(편관) → 시간 戊(비견): 천간극 관계
```

반환 JSON과 반복 삼합 예시는 [현재 요약 예시](root_summary_examples.json)에 보존했다.
문자열을 분해해 관계를 다시 조립하지 않고 기계 처리는 기존 상세 자료와 관계 ID를 사용한다.

## 검증

- 전체 `.venv312/bin/python -m unittest discover -s tests`: **290개 통과**.
- 지지 모든 종류의 쌍, 반복 삼합·방합·삼형, 충 동반 조합에서 요약 행 수와 매트릭스의
  실제 관계 수를 비교했다. 천간은 모든 글자 쌍과 방향별 극을 함께 확인했다.
- 반복 충·육합 상대의 위치, 삼합·방합·삼형의 구성 수, 천간극의 방향과 일간 표기를 고정 사례로 검사했다.
- 원자료 순서를 바꿔도 같은 요약이 나오고 입력 자료를 수정하지 않는지 확인했다.
- 실제 달력 DB를 사용하는 HTTP·OpenAPI에서 필드 교체·중복 목록 제거·통근 개수를 확인했다.
- 고정 입력 4건의 전체 응답을 변경 전후 비교했다. 요약 내용·필드명, 중복 목록 제거와
  매트릭스 버전 외에는 차이가 없었다. 원국·상세 관계·관계 ID·상태·통근·오행·지지 잠정 수치,
  기존 프롬프트와 중앙 글자 조회 결과는 유지됐다.

사용자는 기존 프론트엔드 호환 없이 정리하도록 허용했다.
프론트엔드 연동은 보류 중이며 이번 작업도 커밋·푸시·환경 게시하지 않았다.
