# 맹파 지지·간지 관계 규칙표 초안

이 문서는 `branch_dynamics`의 점수보다 먼저 확정할 **관계 판정 계약**이다. 기준 자료는 아래의 段建業 명의 《盲派初級命理學》 공개 전재본이다. 전재본이므로 원저·판본 대조 전에는 학파 전체의 유일한 정설로 간주하지 않는다. 전통적인 일반 육파 목록과 다른 부분은 별도로 기록한다. **사용자 확인에 따라 子卯는 형(파 작용 없음), 卯午·午酉는 파로 확정했다.**

실행 코드가 직접 읽는 규칙의 단일 원본은 [`services/relation_rules.py`](../services/relation_rules.py)이다. 이 문서는 규칙의 의미와 확정 상태를 설명한다. 관계 탐지와 자합 판정, 지지 작용 점수는 모두 해당 모듈을 가져와 사용한다. `services/constants.py`의 관계 이름은 기존 가져오기 경로를 위한 별칭이다.

- 기준 자료: [段建業 盲派初級命理學 전재본](https://www.scribd.com/document/808919006/%E6%AE%B5%E5%BB%BA%E4%B8%9A%E7%9B%B2%E6%B4%BE%E5%88%9D%E7%BA%A7%E5%91%BD%E7%90%86%E5%AD%A6)
- 보조 대조: [盲派高級班面授班筆記 전재본](https://m.diyifanwen.net/c23val3wonn1emx02t1ml_4.html)
- 이 문서의 상태: **부분 확정**. 子卯형과 卯午·午酉파는 사용자 지정 기준으로 적용했다. 다른 관계의 활성·효과 규칙은 검토 중이다.

## 조합별 작용 규칙: 첫 적용 범위

[`services/relation_rules.py`](../services/relation_rules.py)의 `PAIR_ACTION_RULES`는 조합별 `primary_relation`, 관계마다 다른 **양방향 계수**, 방향별 작용 이름, 작용 상태를 담는다. 아래 수치는 기존 v2 상대 모델의 잠정 계수를 조합별로 배치한 값이며 학파 자료에서 측정된 절대 강도가 아니다. 실제 우세 지지는 월령·동주 천간·주변 지지·거리까지 반영한 비교값으로 정한다.

| 조합 | 주관계 | 방향별 작용 | 현재 조건 처리 |
| --- | --- | --- | --- |
| 子丑 | 육합 후보 | 子水의 합반, 丑 중 辛金의 폐기 후보 | 사이에 낀 인접 충은 합 억제, 합 밖 인접 충은 합·충 병존으로 강도 유보. 土는 후보 오행이며 합화 확정 아님. |
| 寅亥 | 육합 후보 | 亥→寅 생, 亥의 기운 유출·寅의 지원; 寅 중 丙火 손상 후보 | 木은 후보 오행이며 합화 확정 아님. |
| 卯戌 | 육합 후보 | 卯→戌 극; 戌 중 丁火 폐기 후보 | 火는 후보 오행이며 합화 확정 아님. |
| 子午 | 충 | 양쪽 충 1.00씩, 子→午 극 0.80 | 충과 극을 별도 사건으로 보존한다. |
| 子卯 | 무례지형 | 양쪽 형 0.75씩 | 파 후보·파 작용은 출력하지 않는다. 子→卯의 생 후보와 배경 지원은 형에 의한 억제로 `suppressed` 처리한다. |
| 卯午 | 파 | 양쪽 파 0.45씩 | 卯→午의 생 후보와 배경 지원을 `suppressed`로 기록하고 작용량은 0이다. |
| 午酉 | 파 | 양쪽 파 0.45씩, 午→酉 극 0.80 | 사용자 확인에 따라 午酉파를 적용한다. 파와 극의 방향을 구별한다. |
| 辰酉 | 육합 후보 | 辰→酉 생, 辰의 기운 유출·酉의 지원; 辰 중 癸水 폐기·乙木 손상 후보 | 金은 후보 오행이다. 乙木 손상은 辰의 동주 천간과 주변 세력을 더 확인해야 한다. |
| 巳申 | 육합 후보 | 巳→申 극; 巳 중 丙火 손상 후보 | 水는 후보 오행이며 합화 확정 아님. 寅巳申 삼형 구조와 중첩될 수 있다. |
| 午未 | 육합 후보 | 午→未 생, 午의 기운 유출·未의 지원; 未 중 乙木 폐기 후보 | 土는 후보 오행이며 합화 확정 아님. |
| 寅巳·寅申 | 천/해·충 | 주작용만 확정; 방향별 계수는 기존 유형 기본값 | 巳申과 함께 세 글자가 모두 있으면 별도의 무은지형 구조 후보를 출력한다. 삼형 자체 점수는 0으로 둔다. |
| 丑未·丑戌·戌未 | 충·형·형 | 주작용만 확정; 방향별 계수는 기존 유형 기본값 | 세 글자가 모두 있으면 별도의 지세형 구조 후보를 출력한다. 삼형 자체 점수는 0으로 둔다. |
| 丙戌·壬戌 | 동주 자합 후보 | 천간과 해당 지장간의 합 | 戌未형이 필요하고 戌辰충이 있으면 자합을 비활성화한다. |

`activation_status: potential`은 해당 조합의 **잠재 작용량**을 보여준다는 뜻이다. 합·충으로 현실 사건이 확정된다는 의미가 아니다. `conditional`은 구조 해석을 유보하고, `suppressed`는 현재 규칙상 억제되어 작용량을 0으로 둔다는 뜻이다. 아직 조합별 규칙이 없는 관계는 기존 관계 유형의 미보정 계수를 사용한다.

삼합은 세 지지가 존재하는 후보와 국(局)의 잠재 점수를 구별한다. 중신이 두 자리면 `duplicate_middle` 사유로 `conditional`, 중신에 인접한 외부 지지가 충하면 `adjacent_middle_clash` 사유로 `suppressed`를 출력하며 두 경우 삼합 점수는 0이다. 중신 외 다른 지지의 중복은 각 위치별 성립 조합을 보존한다. 인접 충은 [段建業 명의 교재의 충·합 설명](https://www.scribd.com/document/808919006/%E6%AE%B5%E5%BB%BA%E4%B8%9A%E7%9B%B2%E6%B4%BE%E5%88%9D%E7%BA%A7%E5%91%BD%E7%90%86%E5%AD%A6)을 참고했다. **중신 중복을 유보하는 처리는 이 프로젝트의 잠정 정책**이며 학파 전체의 확정 규칙으로 주장하지 않는다. 국의 `potential`도 실제 합화나 길흉을 확정하지 않는다.

생지에 인접한 외부 지지가 충하면 `adjacent_birth_clash`, 성지(묘고)에 인접한 외부 지지가 충하면 `adjacent_tomb_clash`로 완전한 삼합 후보를 억제한다. 두 경우 모두 중신에 충이 없으면 **충받지 않은 날개와 중신의 반합 후보**를 별도 출력하고 `condition_evidence.fallback_from`에 원래 삼합과 충받은 위치를 기록한다. `巳亥卯未`는 木삼합 점수 0과 卯未 반합 후보, `亥卯未丑`은 木삼합 점수 0과 亥卯 반합 후보로 나온다. 중신이 충받으면 잔존 반합을 자동 출력하지 않는다. [교재 전재본](https://pdfcoffee.com/175442--pdf-free.html)은 생지 亥가 巳에게 충받을 때 반합이 남는 사례를 명시한다. **성지 충에 같은 구조를 적용한 것은 이 프로젝트의 잠정 확장**이다.

공합과 지장간 암합은 서로 다른 후보로 탐지한다. 공합은 寅戌→午, 亥未→卯, 申辰→子, 巳丑→酉처럼 빠진 중신을 표시하며, 중신이 이미 있으면 공합 대신 완성 삼합을 탐지한다. 지장간 암합은 寅丑의 戊癸·丙辛·甲己, 午亥의 丁壬·己甲, 卯申의 乙庚을 근거로 표시한다. [段建業 명의 교재의 암합 설명](https://www.scribd.com/document/808919006/%E6%AE%B5%E5%BB%BA%E4%B8%9A%E7%9B%B2%E6%B4%BE%E5%88%9D%E7%BA%A7%E5%91%BD%E7%90%86%E5%AD%A6)과 [개정판의 상세 조합](https://vr-d.com/pdf-file/%E7%9B%B2%E6%B4%BE%E5%91%BD%E7%90%86%28%E4%BF%AE%E8%AE%A2%E7%89%88%29-%E6%AE%B5%E5%BB%BA%E4%B8%9A%E8%91%97.pdf)을 대조했다. 두 유형은 `candidate_only`로 출력하고 현재 점수와 양방향 작용량은 0이다. 천간합의 오행은 `combined_element_candidate`로만 표시하며 합화 성립을 뜻하지 않는다.

육합에서는 충하는 글자가 두 합 글자 사이에 있고 그중 하나에 인접하면 `suppressed`로 판정한다(`子午丑`). 충하는 글자가 합 밖에 있으면서 충할 글자에 인접하면 합과 충이 병존하는 `conditional` 후보로 보존하고, 강도를 확정할 근거가 없어 현재 합 점수와 양방향 작용량은 0으로 둔다(`午子丑`). 충할 글자와 떨어지면 합 후보를 유지한다(`子丑午`). 여섯 쌍의 폐기·손상 항목은 `candidate_hidden_stem_effects`에 `candidate_only`로 보존하며 힘과 점수에 더하지 않는다. 실제 합화와 지장간 작용의 발현을 확정하지 않는다. [段建業 명의 교재의 육합·충합 설명](https://pdfcoffee.com/--6503-pdf-free.html)

조화 총점은 **이 프로젝트의 집계 정책**으로 산출한다. 점수가 있는 삼합·방합의 실제 `formations` 하나에 육합·반합의 두 위치가 모두 포함되면, 쌍 관계와 개별 `score`는 남기고 총점 기여 `score_contribution`만 0으로 둔다. `score_covered_by`에는 포함한 다자 관계의 `relation_id`를 기록한다. 다자 관계가 억제되어 점수 0이면 쌍의 기여를 제거하지 않는다. 예를 들어 `巳午未寅`의 방합에 포함된 午未 육합은 후보로 남지만 조화 총점에는 방합과 중복해 더하지 않는다. 이는 관계의 성립이나 실제 작용을 지우는 규칙이 아니며, 학파 자료에서 제시한 정량 공식도 아니다.

## 판정 단계

1. **후보 탐지**: 정해진 지지 쌍·삼자 조합과 동주 천간·지장간 조합을 위치별로 찾는다. 이 단계에서 `합화`, `제거`, `피해`, `길흉`을 단정하지 않는다.
2. **구조 확인**: 인접 여부, 중신의 중복, 삼합 완성 여부, 동주 자합의 조건, 동일 쌍의 중첩을 확인한다.
3. **작용 판정**: 충·합·천·파 등 다른 관계로 인해 생이 중단되거나 합국이 깨지는지를 확인한다. 결과는 `active`, `suppressed`, `conditional`, `undetermined`와 사유 코드로 기록한다.
4. **방향과 세력**: 활성 관계에 한해 누가 생·극·견인·충격을 가하는지 산출한다. 지장간의 상호 극, 월령, 동주 천간, 다른 지지의 세력과 거리를 사용한다. 비슷한 세력은 우세 미정으로 둔다.
5. **해석**: 빈주, 궁위, 십신은 위 관계 결과에 덧붙인다. 관계의 존재·작용 여부를 빈주 분류로 바꾸지 않는다.

같은 두 지지에 여러 후보가 있을 수 있다. **후보를 삭제하지 않고**, 주작용과 부수작용 및 억제 사유를 기록한다. 예를 들어 寅巳는 천이 주작용이고 삼형의 일부이다. 寅申은 충, 巳申은 육합이 주작용이며 寅巳申 세 지지가 모두 있으면 삼형의 뜻을 추가한다. [형의 완성 조건과 쌍별 주작용](https://www.scribd.com/document/808919006/%E6%AE%B5%E5%BB%BA%E4%B8%9A%E7%9B%B2%E6%B4%BE%E5%88%9D%E7%BA%A7%E5%91%BD%E7%90%86%E5%AD%A6)

## 지지 관계 후보표

| 유형 | 후보 | 성립·작용 판정 |
| --- | --- | --- |
| 육합 | 子丑, 寅亥, 卯戌, 辰酉, 巳申, 午未(합土) | 결합 후보. 午未의 후보 오행은 사용자 확인에 따라 土로 둔다. 합이라고 무조건 길하거나 실제 합화했다고 출력하지 않는다. 조합별로 조합·극합·폐기·합상·합반 여부를 구별한다. |
| 육충 | 子午, 丑未, 寅申, 卯酉, 辰戌, 巳亥 | 대립 후보. 양쪽 모두 충을 주고받지만 오행 극 방향은 따로 기록한다. 근접 충과 격위 충을 구별한다. 辰戌·丑未는 창고의 개폐도 따로 본다. |
| 삼합 | 申子辰 水, 亥卯未 木, 寅午戌 火, 巳酉丑 金 | 세 위치가 모두 있으면 구조 후보. 중신 중복 시 성립 유보, 세 글자 중 하나에 인접 충이 있으면 완전한 국의 점수를 억제한다. 생지·성지 충은 남은 반합 후보를 따로 본다. |
| 반합 | 申子·子辰, 亥卯·卯未, 寅午·午戌, 巳酉·酉丑 | 중신이 포함된 두 지지 결합 후보. 삼합보다 약한 구조로 구별한다. |
| 공합 | 申辰, 亥未, 寅戌, 巳丑 | 중신이 없는 두 지지. 반합이나 지장간 암합과 혼동하지 않는다. |
| 지장간 암합 | 寅丑, 午亥, 卯申 | 각 지지의 지장간이 서로 천간합을 이루는 후보. 공합과 다른 관계이다. |
| 삼형 | 寅巳申, 丑戌未 | 세 지지가 완비되면 삼형 구조. 寅巳·寅申·巳申 두 지지만 있으면 각각 천·충·육합을 주작용으로 둔다. 丑戌·未戌은 두 지지 형으로도 본다. 丑未는 충을 우선한다. |
| 천/해 | 子未, 丑午, 寅巳, 卯辰, 申亥, 酉戌 | 맹파 자료에서 `穿`으로 다루는 쌍. 寅巳·申亥는 생을 동반할 가능성도 함께 기록하되 자동으로 이득·피해를 확정하지 않는다. |
| 무례지형 | 子卯 | 이 프로젝트에서는 형으로만 판정하고 파 작용은 출력하지 않는다. 子→卯의 생 후보는 형에 의해 억제한다. |
| 파: 이 프로젝트 기준 | 卯午, 午酉 | 卯午는 오행상 생의 경로가 있어도 파가 우세하여 `생하지 않음`을 명시한다. 午酉는 火克金과 겹친다. |
| 생·극 | 지지 대표 오행의 5행상 방향 및 지장간별 상호 작용 | **오행상 가능한 방향**과 **실제 발현**을 구별한다. 특히 子卯·卯午의 생을 자동 활성화하지 않는다. 합·충·천·형과 겹칠 때 주작용을 먼저 판단한다. |

육합과 조합별 세부 작용은 [육합 설명](https://www.scribd.com/document/808919006/%E6%AE%B5%E5%BB%BA%E4%B8%9A%E7%9B%B2%E6%B4%BE%E5%88%9D%E7%BA%A7%E5%91%BD%E7%90%86%E5%AD%A6), 삼합·반합·공합·암합은 [삼합·암합 설명](https://www.scribd.com/document/808919006/%E6%AE%B5%E5%BB%BA%E4%B8%9A%E7%9B%B2%E6%B4%BE%E5%88%9D%E7%BA%A7%E5%91%BD%E7%90%86%E5%AD%A6), 충·형·파는 [충·형·파 설명](https://www.scribd.com/document/808919006/%E6%AE%B5%E5%BB%BA%E4%B8%9A%E7%9B%B2%E6%B4%BE%E5%88%9D%E7%BA%A7%E5%91%BD%E7%90%86%E5%AD%A6)을 따른다.

## 동주 관계와 자합

각 기둥의 천간과 지지를 별도 노드로 보며 `천간 → 지지`, `지지 → 천간`, `천간 ↔ 지장간 자합`을 구별한다. 이 기준 자료에서는 천간이 지지를 극할 수 있고, 지지가 천간을 생할 수 있지만 **지지의 천간 직접 극은 자합 예외가 아닌 한 인정하지 않는다**. 그러므로 월간이 월지를 극하는지, 월지가 월간을 생해 기운을 내보내는지, 월간이 월지를 생하는지를 별도로 판단한다. [간지 생극 원리 및 자합 목록](https://www.scribd.com/document/808919006/%E6%AE%B5%E5%BB%BA%E4%B8%9A%E7%9B%B2%E6%B4%BE%E5%88%9D%E7%BA%A7%E5%91%BD%E7%90%86%E5%AD%A6)

| 자합 후보 | 자합 상대 지장간 | 조건 |
| --- | --- | --- |
| 丁亥 | 壬 | 기본 후보 |
| 己亥 | 甲 | 기본 후보 |
| 辛巳 | 丙 | 기본 후보 |
| 癸巳 | 戊 | 기본 후보 |
| 壬午 | 丁 | 기본 후보 |
| 甲午 | 己 | 기본 후보 |
| 戊子 | 癸 | 기본 후보 |
| 丙戌 | 辛 | 戌이 未와 형을 이루어야 후보가 활성화됨. 辰沖이면 불성립. |
| 壬戌 | 丁 | 戌이 未와 형을 이루어야 후보가 활성화됨. 辰沖이면 불성립. |

자합은 **같은 기둥 천간과 그 지지의 지장간 사이** 관계이며, 기둥 사이의 천간합·지지합을 자동 의미하지 않는다. `combined_element`는 천간합의 관습적 결과 오행 후보이지 실제 합화 성립 판정이 아니다. 위 조건 외 다른 충·합·천의 영향은 원문에서 일괄 규칙을 확정할 근거가 부족하므로 `undetermined`로 남긴다.

## 구현 전에 결정할 정책

1. **학파 프로필**: 子卯는 형, 卯午·午酉는 파를 현재 프로젝트 규칙으로 확정했다. 다른 자료의 분류를 이 후보 집합에 무차별로 합치지 않는다.
2. **전재본의 내부 상충**: 파 설명의 앞부분은 `午酉`, 뒤의 목록은 `卯酉`이다. 사용자가 이 프로젝트의 해석 기준을 `午酉`로 확인했으므로 구현은 午酉를 따른다. 전재본의 불일치는 자료 검증 기록으로 남긴다.
   [맹파 고급반 필기 전재본](https://m.diyifanwen.net/c23val3wonn1emx02t1ml_4.html)은 子卯를 형 목록에 넣으면서도 파를 주로 본다고 적는다. 이 프로젝트는 사용자가 확인한 **子卯형·파 작용 없음**을 우선 적용한다.
3. **합화와 합의 효과**: 결합 후보, 합반, 조합, 극합, 폐기, 합상의 상세 발현 조건을 독립 규칙으로 만든다. 전재본에 `午未`의 화·토 귀속 표현이 혼재하지만, 이 프로젝트의 午未합 후보 오행은 사용자 확인에 따라 **土**로 둔다. 후보 오행과 실제 합화 성립 여부는 별도로 판정하며, 후보를 곧바로 `transformed_element`로 확정하지 않는다.
4. **점수화**: 관계 후보 정합성 → 활성 판정 → 방향성 → 세력 산식 순으로 검증한다. 자료에 없는 임의 계수는 해석론적 사실로 표기하지 않는다.

## 필수 검증 사례

- 子卯: 형만 탐지되고 파는 없으며, 子→卯의 생은 `punishment_blocks_generation`으로 억제된다.
- 卯午: 파가 탐지되고 卯→午의 생은 `break_blocks_generation`으로 억제된다.
- 寅巳, 寅申, 巳申: 두 지지만 있으면 각각 천·충·육합이 주작용이다. 세 지지가 모이면 삼형의 구조가 추가된다.
- 丑未와 丑戌: 각각 충과 형의 주작용을 구별한다.
- 寅戌·亥未·申辰·巳丑: 중신이 없으면 공합 후보, 중신이 있으면 삼합 후보이다. 반합·지장간 암합으로 잘못 분류하지 않는다.
- 寅丑·午亥·卯申: 지장간의 천간합 조합과 위치를 기록하고 공합과 구별한다.
- 亥卯未에 卯가 두 위치: 중신 중복으로 삼합 완성을 유보한다. 酉가 卯에 밀착해 충하면 합국 훼손 사유가 남는다.
- 巳亥卯未: 亥가 巳에게 인접 충을 받아 木삼합 점수 0, 卯未 후반합 후보 출력.
- 亥卯未丑: 未가 丑에게 인접 충을 받아 木삼합 점수 0, 亥卯 전반합 후보 출력. 성지 충 후 반합은 잠정 정책.
- 丙戌·壬戌: 未 형 유무와 辰沖 유무를 바꿔 자합의 조건과 차단을 검증한다.
- 辛巳, 癸巳와 다른 월간 조합: 동주 자합, 천간의 지지 극, 지지의 천간 생을 서로 다른 관계로 기록한다.
- 같은 두 지지의 합·형·파 중첩: 후보는 모두 추적하되 주작용의 힘을 중복 합산하지 않는다.
