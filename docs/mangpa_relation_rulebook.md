## 조합별 작용 규칙: 첫 적용 범위

[`services/relation_rules.py`](../services/relation_rules.py)의 `PAIR_ACTION_RULES`는 검토된 조합의 정적 기본 분류인 `primary_relation`, 관계마다 다른 **양방향 계수**, 방향별 작용 이름, 작용 상태를 담는다. `primary_relation`은 실제 성립·우세 판정이 아니다. 아래 수치는 기존 v2 상대 모델의 잠정 계수를 조합별로 배치한 값이며 학파 자료에서 측정된 절대 강도가 아니다. 실제 우세 지지는 월령·동주 천간·주변 지지·거리까지 반영한 비교값으로 정한다.

`activation_status: potential`은 해당 조합의 **잠재 작용량**을 보여준다는 뜻이다. 합·충으로 현실 사건이 확정된다는 의미가 아니다. `conditional`은 구조 해석을 유보하고, `suppressed`는 현재 규칙상 억제되어 작용량을 0으로 둔다는 뜻이다. 아직 조합별 규칙이 없는 관계는 기존 관계 유형의 미보정 계수를 사용한다.

삼합은 세 종류 지지의 구성, 중신 위치·개수, 실제 세 자리 조합을 사실로 제공한다. 중신 중복과 중신·생지·성지의 인접 충은 관찰 코드와 근거로 보존하고 삼합 상태는 모두 `detected`다. [존재 정보 통일 계약](hap_presence_migration.md)을 따른다.

삼합 생지·성지에 인접 충이 있으면 해당 충과 다른 날개·중신의 반합 후보를 함께 기록한다. 삼합 구성을 지우거나 억제하지 않는다. 날개 충을 이유로 구성의 존재를 지우지 않는다. [현행 처리와 수치 범위](hap_presence_migration.md)를 참조한다.

공합과 지장간 암합은 서로 다른 후보로 탐지한다. 공합은 寅戌→午, 亥未→卯, 申辰→子, 巳丑→酉처럼 빠진 중신을 표시하며, 중신이 이미 있으면 공합 대신 완성 삼합을 탐지한다. 지장간 암합은 寅丑의 戊癸·丙辛·甲己, 午亥의 丁壬·己甲, 卯申의 乙庚을 근거로 표시한다. [段建業 명의 교재의 암합 설명](https://www.scribd.com/document/808919006/%E6%AE%B5%E5%BB%BA%E4%B8%9A%E7%9B%B2%E6%B4%BE%E5%88%9D%E7%BA%A7%E5%91%BD%E7%90%86%E5%AD%A6)과 [개정판의 상세 조합](https://vr-d.com/pdf-file/%E7%9B%B2%E6%B4%BE%E5%91%BD%E7%90%86%28%E4%BF%AE%E8%AE%A2%E7%89%88%29-%E6%AE%B5%E5%BB%BA%E4%B8%9A%E8%91%97.pdf)을 대조했다. 두 유형은 `candidate_only`로 출력하고 양방향 잠정 작용량은 기존 정책상 0이며 실제 적용량을 뜻하지 않는다. 천간합의 오행은 `combined_element_candidate`로만 표시하며 합화 성립을 뜻하지 않는다.

육합의 인접 충은 조합 사이(`intervening_adjacent_clash`)와 바깥(`external_adjacent_clash`)을 구분해 사실로 제공한다. 조합 자체는 모두 `detected`이며 충이 있다고 불성립·유보를 판정하지 않는다. 여섯 쌍의 지장간 폐기·손상 항목은 후보로만 유지하고 실제 합화·작용 발현은 확정하지 않는다.

관계 매트릭스의 점수·총계와 빈주의 별도 점수·전체 우세·취용 방향은 제거했다.
같은 다자 조합 안의 쌍 관계도 ID·참여 위치로 보존한다.
`formation_evidence[].overlapping_pairs`는 실제 포함된 쌍의 `relation_id`와
`participants`만 기록하며 점수 중복 차감으로 관계의 존재를 가리지 않는다.
[현재 응답 계약](relation_score_retirement.md)을 따른다.

### 다자 합의 방향 후보

실행 규칙 `GROUP_ACTION_RULES`는 네 삼합과 네 방합을 조합별로 기록한다. 삼합의 생지·묘고에서 중신으로 향하는 두 경로는 **중신을 중심으로 모이는 구조 후보**이며, 어느 글자가 실제로 더 강하게 끌어오는지에 대한 확정 판정이 아니다. 寅午戌의 戌은 午로부터 생받을 가능성, 다른 세 삼합의 묘고는 합에 따른 변화 가능성을 각각 별도 후보로 둔다. [段建業 명의 《盲派初級命理學》 전재본의 삼합 설명](https://pdfcoffee.com/175442--pdf-free.html)은 중신의 중요성, 중신 중복·충의 훼손, 寅午戌과 다른 삼합의 묘고 작용 차이를 기술한다. 전재본에서 수치화된 글자별 힘이나 사주 전체 조건에 따른 견인 방향 공식은 확인되지 않았으므로 `candidate_only`로 남긴다.

방합의 네 조합은 계절적 결속 후보로 기록하며 개별 견인 방향은 `undetermined`다. 삼합도 사실 탐지만으로 실제 방향·주도를 정하지 않는다. 내부 모형의 중신 방향은 구조 후보로만 남긴다.

**현재 계산과 v3 목표의 구분:** 현재 계산기는 완성 삼합의 내부 `생지–중신`·`중신–묘고`를 국의 구성 근거로 추적하되, 별도 반합 관계나 작용량으로 출력하지 않는다. [v3 목표 출력](archive/strength-research/branch_dynamics_v3.json)에서는 내부 반합을 `pairwise[].relations[]`에 한 번 기록하고 그룹의 `component_pairs[].relation_id`로 참조한다. 이때 `activation_status: candidate_only`, `formation_status: included_in_complete_group`, `effect_status: structural_only`, `direction: null`, `metrics: null`이며 독립 작용량과 경합 판정 대상이 아니다. 삼합이 깨져 반합만 남으면 그 반합을 독립 쌍 관계로 출력하고 잠재 작용량을 평가한다. 방합에는 독립 작용량을 부여하지 않으며, 함께 탐지된 육합 등 쌍 관계의 작용량은 유지한다. 그룹 `status: not_scored`는 현재 계산 정책에 따른 상태이고, 중신이나 방합의 가운데 글자를 자동 주도자로 판정하지 않는다.

**동일 지지와 자형의 v3 출력 정책:** `same_branch`는 동일 지지가 두 위치에 존재한다는 구조 사실이며 독립 작용량이 없다(`effect_status: structural_only`, `calculation_status: not_applicable`, `metrics: null`). `self_punishment`는 별도 관계로 두고 인접한 辰辰·午午·酉酉·亥亥만 `active`, 격위는 `candidate_only`로 기록한다. 두 상태 모두 독립 작용량은 미정이므로 `calculation_status: pending`, `metrics: null`이다. 현재 계산기의 자형 탐지·잠재 `force`는 실제 적용량과 구분한다.

이 표는 **현재 구현의 결과**를 설명한다. v3에서는 완성 삼합의 구성 쌍을 `pairwise`에 구조 전용 반합 후보로 노출하고 그룹에서 해당 ID를 참조한다. 그다음 수치화 검토 대상은 삼합의 중신 집중을 실제 견인 방향으로 바꾸는 조건과 반복 지지의 두 조합이 한 글자에 미치는 영향을 합치는 방법이다.

## 판정 단계

1. **후보 탐지**: 정해진 지지 쌍·삼자 조합과 동주 천간·지장간 조합을 위치별로 찾는다. 이 단계에서 `합화`, `제거`, `피해`, `길흉`을 단정하지 않는다.
2. **구조 확인**: 인접 여부, 중신의 중복, 삼합 완성 여부, 동주 자합의 조건, 동일 쌍의 중첩을 확인한다.
3. **작용 판정**: 충·합·천·파 등 다른 관계로 인해 생이 중단되거나 합국이 깨지는지를 확인한다. 결과는 `active`, `suppressed`, `conditional`, `undetermined`와 사유 코드로 기록한다.
4. **방향과 세력**: 활성 관계에 한해 누가 생·극·견인·충격을 가하는지 산출한다. 지장간의 상호 극, 월령, 동주 천간, 다른 지지의 세력과 거리를 사용한다. 비슷한 세력은 우세 미정으로 둔다.
5. **해석**: 빈주, 궁위, 십신은 위 관계 결과에 덧붙인다. 관계의 존재·작용 여부를 빈주 분류로 바꾸지 않는다.

같은 두 지지에 여러 후보가 있을 수 있다. **후보를 삭제하지 않고**, 주작용과 부수작용 및 억제 사유를 기록한다. 예를 들어 寅巳는 천이 주작용이고 삼형의 일부이다. 寅申은 충, 巳申은 육합이 주작용이며 寅巳申 세 지지가 모두 있으면 삼형의 뜻을 추가한다. [형의 완성 조건과 쌍별 주작용](https://www.scribd.com/document/808919006/%E6%AE%B5%E5%BB%BA%E4%B8%9A%E7%9B%B2%E6%B4%BE%E5%88%9D%E7%BA%A7%E5%91%BD%E7%90%86%E5%AD%A6)

**v3 쌍별 생·극 억제 정책:** 별도로 성립한 파·천·충·쌍별 형은 같은 위치 쌍의 생·극을 기존 기준으로 억제한다. 원국 육합은 전부 사실 탐지이므로 자동으로 생·극을 억제하지 않는다. 수치 식·계수는 그대로이며 제거한 자동 성립 연결 때문에 일부 배경 잠정값은 달라진다. 내부 모형과 실제 적용량을 구분한다.

**현재 쌍별 기준:** 파·충·천·쌍별 지세형의 존재·거리 규칙과 인접 자형·삼형 규칙은 유지한다. 육합·삼합·자합은 전체 조합 존재를 `detected`로 기록한다. 합의 충·중복 관찰만으로 성립·불성립을 정하지 않으며 육합 성립을 근거로 한 생·극 자동 억제도 하지 않는다.

## 동주 관계와 자합

각 기둥의 천간과 지지를 별도 노드로 보며 `천간 → 지지`, `지지 → 천간`, `천간 ↔ 지장간 자합`을 구별한다. 이 기준 자료에서는 천간이 지지를 극할 수 있고, 지지가 천간을 생할 수 있지만 **지지의 천간 직접 극은 자합 예외가 아닌 한 인정하지 않는다**. 그러므로 월간이 월지를 극하는지, 월지가 월간을 생해 기운을 내보내는지, 월간이 월지를 생하는지를 별도로 판단한다. [간지 생극 원리 및 자합 목록](https://www.scribd.com/document/808919006/%E6%AE%B5%E5%BB%BA%E4%B8%9A%E7%9B%B2%E6%B4%BE%E5%88%9D%E7%BA%A7%E5%91%BD%E7%90%86%E5%AD%A6)

| 자합 후보 | 자합 상대 지장간 | 초급 자료의 해설 조건 — 자동 판정하지 않음 |
| --- | --- | --- |
| 丁亥 | 壬 | 기본 후보 |
| 己亥 | 甲 | 기본 후보 |
| 辛巳 | 丙 | 기본 후보 |
| 癸巳 | 戊 | 기본 후보 |
| 壬午 | 丁 | 기본 후보 |
| 甲午 | 己 | 기본 후보 |
| 戊子 | 癸 | 기본 후보 |
| 丙戌 | 辛 | 戌이 未와 형을 이루어야 후보가 활성화됨. 辰沖이면 불성립. |
| 壬戌 | 丁 | 戌이 未와 형을 이루어야 후보가 활성화됨. 辰沖이면 불성립. |

자합은 **같은 기둥 천간과 그 지지의 지장간 사이** 관계이며, 기둥 사이의 천간합·지지합을 자동 의미하지 않는다. `candidate_element`는 천간합의 관습적 결과 오행 후보이지 실제 합화 성립 판정이 아니다. 위 표는 문헌 해설을 보존한 것이다. 현재 API는 모든 등록 자합을 `detected`로 제공하고 주변 충·형을 별도로 기록한다. 초급 전사본의 일반적인 충 제약과 중급의 6개 분류 등 자료 차이는 [별도 검토](self_combination_source_review.md)에 기록했으며 실제 영향은 미평가다.

## 구현 전에 결정할 정책

1. **학파 프로필**: 子卯·卯午·午酉는 파 후보를 현재 프로젝트 규칙으로 확정했다. 子卯는 형 후보에서 제외한다. 다른 자료의 분류를 이 후보 집합에 무차별로 합치지 않는다.
2. **전재본의 내부 상충**: 파 설명의 앞부분은 `午酉`, 뒤의 목록은 `卯酉`이다. 사용자가 이 프로젝트의 해석 기준을 `午酉`로 확인했으므로 구현은 午酉를 따른다. 전재본의 불일치는 자료 검증 기록으로 남긴다.
   [맹파 고급반 필기 전재본](https://m.diyifanwen.net/c23val3wonn1emx02t1ml_4.html)은 子卯를 형 목록에 넣으면서도 파를 주로 본다고 적는다. 이 프로젝트는 사용자 최신 확인에 따라 **子卯를 파로만 출력**한다.
3. **합화와 합의 효과**: 결합 후보, 합반, 조합, 극합, 폐기, 합상의 상세 발현 조건을 독립 규칙으로 만든다. 전재본에 `午未`의 화·토 귀속 표현이 혼재하지만, 이 프로젝트의 午未합 후보 오행은 사용자 확인에 따라 **土**로 둔다. 후보 오행과 실제 합화 성립 여부는 별도로 판정하며, 후보를 곧바로 `transformed_element`로 확정하지 않는다.
4. **점수화**: 관계 후보 정합성 → 활성 판정 → 방향성 → 세력 산식 순으로 검증한다. 자료에 없는 임의 계수는 해석론적 사실로 표기하지 않는다.

## 필수 검증 사례

- 子卯: 파는 `active`이고 형은 없다. 子→卯 생 후보는 남지만 독립 적용량과 주변 보정은 0이다.
- 卯午: 파는 `active`이고 卯→午 생 후보는 남지만 독립 적용량과 주변 보정은 0이다.
- 寅巳, 寅申, 巳申: 두 지지만 있으면 각각 천·충·육합이 주작용이다. 세 지지가 모이면 삼형의 구조가 추가된다.
- 丑未와 丑戌: 각각 충과 형의 주작용을 구별한다.
- 寅戌·亥未·申辰·巳丑: 중신이 없으면 공합 후보, 중신이 있으면 삼합 후보이다. 반합·지장간 암합으로 잘못 분류하지 않는다.
- 寅丑·午亥·卯申: 지장간의 천간합 조합과 위치를 기록하고 공합과 구별한다.
- 亥卯未에 卯가 두 위치: 중신 두 위치·두 조합을 보존하고 상태는 detected다. 卯에 인접한 酉충도 사실로 보존한다.
- 巳亥卯未: 亥가 巳에게 인접 충을 받아 木삼합 점수 0, 卯未 후반합 후보 출력.
- 亥卯未丑: 未가 丑에게 인접 충을 받아 木삼합 점수 0, 亥卯 전반합 후보 출력. 성지 충 후 반합은 잠정 정책.
- 丙戌·壬戌: 未형·辰충의 유무와 반복 위치를 바꿔 조합 존재는 유지하고 주변 관계만 달라지는지 검증한다.
- 辛巳, 癸巳와 다른 월간 조합: 동주 자합, 천간의 지지 극, 지지의 천간 생을 서로 다른 관계로 기록한다.
- 같은 두 지지의 합·형·파 중첩: 후보는 모두 추적하되 주작용의 힘을 중복 합산하지 않는다.

> 이 규칙표는 공개 교재의 관계 판정에 대한 기술적 재구성이다. 사주 사건·길흉에 대한 검증된 예측식이 아니다.
