## 뿌리 전체 제외의 실행 반례 후보

전수 집계는 정확 일치·양수 30쌍, 동오행만·양수 16쌍, 정확 일치·0 3쌍, 동오행만·0 9쌍, 동오행 없음·0 62쌍이다. 양수 46쌍 모두 동오행 지장간을 갖지만, 역은 성립하지 않는다. 기존 19쌍 불일치 검토에 더해 **乙亥·丙未·丙戌·丁寅·己寅·己申·己亥·辛巳·癸申**의 9쌍도 인정 기준의 대조군으로 남긴다. 특히 丁巳는 인정하지만 丙未·丙戌은 제외하므로, 동오행이 있다는 사실만으로 자동 인정하는 규칙을 만들 수 없다.

다음 구현 전에 우선순위 1의 인정 여부와 뿌리 전체 제외 조건을 근거와 함께 확정한다. 확정한 사례를 회귀 테스트로 추가하고 규칙 버전·응답 계약·실제 원국 변경 대조를 함께 갱신한다. 타주 지원을 동주 통근으로 합산하거나 통근 개수로 전체 신강·신약을 단정하지 않는다.
